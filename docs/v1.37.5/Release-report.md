# lotraAI Image2Slide 1.37.5

1.37.5 基于 1.37.4，修复原图重建中的执行恢复与证据身份问题，并把字号、字体家族和居中检查接入普通组件工作流。文字、表格和公式显式字号使用统一 pt，按 0.5 pt 十进制就近舍入、中点向上；源字形与真实绑定字体进行有限物理字号拟合，原生写入前检查、写入后立即读回属性。中文与英文使用各自有限字体集合，先识别视觉家族，再按有界强证据细分实际字面。整段墨迹位置在横纵两个轴检查，保留原图有意偏移。

原图语义内容能够可靠界定时，可选择内容轮廓；否则保留全图恢复。原始字节及可逆映射始终保留，语义裁取不自动建立透视校正或原画布比例。用户委托按图判断时，可保留多处文字/边界推断、假设、不确定性和留出复核后选择估计工作平面，不能冒充原稿元数据。字号预检失败会返回合法短语采样恢复包，保留暂存字体、预算和失败记录；无支持或有歧义的拟合不能冒充唯一正确字号。事务恢复、惰性状态协议、源线支持、可编辑材质、逻辑/原生文字和首次渲染局部闭合共同进入最终检查。

当前回归覆盖：Windows 523 项通过；Linux 522 项通过、1 项 Windows 专属跳过。历史 R3 私有夹具错误及修复记录保留。当前 R4 双平台完整回归重新执行，Linux 本轮首次安装因自有测试盘空间不足失败，归档自建临时副本并预置同哈希资源后从正式入口恢复，初次结果保留。Windows/Linux 最终载荷首次和重复安装通过，重复安装 475 个技能文件字节和时间戳不变。实际分发入口通过 70 次解析，真实完整包、嵌套载荷及双仓库版本/内容检查 2564 项通过。

原事故由官方 DeepSeek Harness、现有账户和 deepseek-flash/max 实际生成原生候选并用 PowerPoint 渲染，完成了多项局部修正。本轮箭头诊断已闭合：见证点是最坏像素差而非箭头中心，改用较小原生箭头后，走线、端点、拓扑和实际涂料检查通过，源路径和限值保持。本次发布范围为当前诊断闭合后的产品版本；原事故当前仍为 review 检查点，没有整图验收、独立最终审计、正式导出或 delivery-check allow_finish:true，其余组织框/线路/分组外观、布局、延后字体与整图遗漏检查保留为未完成。局部诊断和原生/单位检查不构成整图 PASS，不推出总体 token、时间或多图质量增益。原图、候选 PPT 和私有字体/任务数据不随产品发布。
