# lotraAI 1.37.5：事故恢复、源观测与明确目标

1.37.5 以正式 1.37.4 源码为基线，在既有组件循环内完成三阶段改造。原图理解仍由当前代理负责，程序负责有限动作、测量、恢复和独立检查。产品继续作为可移植 skill 交付，无须替换 Harness、增加模型密钥或安装常驻服务。

## B：在原图和首次实际渲染之间闭合质量

源封存增加独立像素支持检查和局部叠加。边界、线路、短段和文字诊断只提示复查位置，不自动成为源事实。布局必须逐域给出 alignment、containment、connections 的适用性及证据。自由布局和有意偏置继续保留。

每个表面或轮廓声明原图形态，并复查填充、可见深度和角部。可编辑原生效果补充有界外阴影及软边；已有渐变、圆角和表面构造继续适用。源中没有观察到的效果不能由预设自动添加。

文字保留逻辑字面量、颜色和强调跨度，方向及显式软换行单独表达。一个原生竖排文字体可以保留连续逻辑字符串；真实硬换行、空格和列表不被全局归一化。物理中英文字体拆分覆盖普通文本、段落 run 和表格单元格。整串 ink 宽、高、墨迹底边和间距使用原图与实际渲染测量；缺失或混入同色邻居时返回测量或源决策。

短线联合生产器要求完整的显式源图，覆盖每条短臂、端点和邻接关系。缺失对端或归属不明不能依靠较长分支通过。联合包络测量不冒充孤立 shaft 宽度。分支建议保持每个 feature/segment 身份；一个弯折连接器仍只有两个端点，交叉也不自动授权共享边。

真实事故图还暴露了字形内部空隙与字间距的混淆。新增可选的 `spacing_groups`，由当前代理在原图上明确完整逻辑字形组；原始投影仍保留。分组必须完整覆盖源墨迹，顺序互斥，实际渲染必须存在无歧义的组间空白；同时逐组测宽、高、墨迹底边和轴向位置，沿用冻结限值。没有空隙、漏字、未归属源墨迹和边界歧义不能通过。对已采用家族的变更仍走既有源字体 revision 和物理资源重绑定入口；普通 family 提示不能冒充已完成的字体切换。

新任务的首个已保存结果先实际渲染，再逐组件执行 `review_local`。原生结构合格与外观待审是独立状态。局部证据绑定本次原图、PPTX、预览、组件、特征基准和观察者，并运行当前文字与线路探针。完成相关局部闭合后才进入复用和最终布局。仍保留一次延后字体审阅、整图遗漏审阅及全部独立最终门禁。

颜色观察与墨迹几何提取分开：`text_appearance.colours` 和 `colour_tolerance` 为几何探针选择前景，不能单独证明已覆盖全部真实文字或颜色保真。源观察、首次局部审阅和最终审阅都要独立比较原图与当前渲染的颜色及强调跨度。原图近黑而候选深蓝时，即使两者都落在同一提取容差内，颜色疑问仍阻止外观结论。暗芯采样只作定位线索，不自动生成整段重涂值；混色、反锯齿和不确定性保留。错误源调色板走既有 prior-hash 修正和显式重绑定，不放宽容差、不重标历史失败。本次将该约束写入 skill 入口及局部审阅说明，未新增或宣称已验证通用颜色自动判定器。

完整集成还发现并修复了三处接口问题：最终交付检查按任务策略确定准确门禁集合；表格验证接受受限的已编译原生脚本样式；Windows UNO 客户端在操作输出完成而清理阻塞时使用当前 job/result 的严格完成确认。最后一项绑定请求、客户端、输入和全部输出哈希，停止并复核其自有进程后才能返回成功。旧超时输出不能直接采用，缺失、陈旧确认或字节变化仍失败。

实际交付深度的保存重开还要求应用配置与临时目录使用项目私有根内的唯一短路径，避免随交付事务嵌套而不断增长。重定向根路径被拒绝，进程提前退出立即报错；有限超时和自有进程边界保持不变。真实保存副本重开与技术样例的成功，均不代替原事故图的最终验收。

已封存源观察被新生产器发现缺失义务时，局部 feature 修正不能越权修改另一组件的 unit 材质记录。修复复用既有源决策阶段：只有原先保留的观察本身也失败时，才派发绑定该旧观察和精确诊断的源复查 packet；只允许补充诊断所指的行或域，并要求 prior hash 和原图证据。无效新提案不能借机扩大有效旧观察的修改范围。所有旧图、失败、其他待决事项和预算保持，完整预检通过后仍须显式重绑定，才能恢复原生工作。

## C：明确拍摄目标，保留原始投影

开始前先辨识语义内容轮廓；可靠时通过 `semantic_region` 记录原图哈希、观察者、轮廓、内容范围和排除的拍摄环境，只裁取轮廓的整数包络，保留可逆平移。不能可靠界定时按完整原图投影恢复，这也是程序缺省值。另一个可选的 `slide_surface` 透视校正路线仍必须提供原图哈希、四角、输出尺寸、长宽比的原始元数据或用户授权、观测与不确定性。语义裁取不需要伪造原始比例，四角本身不证明原始比例，也不授权重新排齐设计。

任务保留原图、授权文件、派生目标、正反单应变换和误差。最终门禁独立重算坐标映射和派生像素。不能以超分辨率制造证据，不能静默迁移旧任务或已有部分 PPT。拍照、截图、低对比和有意偏置样例使用同一坐标域检验。

字号、间距与段落缩进使用显式 pt，经十进制就近舍入到 0.5 pt，中点向上，例如 12.33→12.5、0.33→0.5；文字、公式和表格共用单位与原生读回检查。专用估计器用原始字形/连续短语、绑定字体的真实字节及 face index，在冻结物理画布内拟合至多 17 个半点候选。原图边缘不确定性与候选栅格量化显式传播，不能靠自由伸缩字形或放宽最终外观界限通过。支持区间内的构建估计仍须真正原生写入、属性读回及实际整段墨迹验证。

中文、英文分别使用有限语言集合，中文选择展示中文家族名，先达到雅黑等视觉家族即可；保留已选真实字面，只有有界强证据才细分变体。构建前冻结横纵对齐、边距与段落意图；写入后逐文本体、run、公式和单元格检查实际属性；渲染后逐整串及明确逻辑组比较横纵墨迹位置，保留原图有意偏移。

用户明确委托按图判断时，可以根据多处独立文字、边界和平行关系选择估计工作平面，保留假设、不确定性和留出位置复核。授权与推断各有明确身份；估计比例不能标作用户提供的原稿元数据，历史原稿 pt 也不因此成为已知。
