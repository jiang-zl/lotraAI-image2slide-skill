# 故障排查

[English](troubleshooting.md) · [README](../README.zh-CN.md)

| 现象 | 检查内容 |
| --- | --- |
| 安装器找不到资源 | 在完整解压后的 bundle 中运行，保留其目录结构。 |
| Linux 大小写检查失败 | 使用区分大小写的 Linux 项目目录，再继续相同安装。 |
| 提示资源被修改或属于其他安装 | 保留文件，先检查诊断指明的具体资源。 |
| 看到 skill 源码但运行时未准备 | 在工作项目执行完整包安装器。 |
| Math runtime 未提供 | 使用当前提供的 Windows/Linux x86-64 路径；Python 引擎资源单独记录。 |
| 安装完成但渲染未验证 | 检查当前任务的实际渲染能力与保存文件的渲染诊断。 |
| 更换宿主后字体或公式不同 | 核对实际字体、字体资源、数学结构和保存文件的显示。 |
| 工作中断 | 使用同一原图和项目状态恢复已登记任务。 |

查看 `.lotraAI-build/Bundle-install.json`，以及安装器或当前工作包指定的具体诊断。相关字段包括产品版本、环境、核心准备、渲染状态、原生编辑准备与 skill 入口。反馈时提供与问题直接相关的诊断，分享前检查其中的私有内容。
