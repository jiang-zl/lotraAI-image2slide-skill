# lotraAI Image2Slide 1.37.4

Based on published 1.37.3, this release repairs the font preparation contract and
its interaction with source text, native slots and finite component decisions.
The product remains a self-contained project skill.

Every ordinary run and table cell gets a complete verified latin/ea/cs plan.
Writer and expected-style checks share its resolution; independent saved-byte
checks still verify original literals, logical colour/emphasis intervals, actual
slots and bound resource identity. A Chinese binding that differs from a font
hint no longer produces false unused-slot failures. Mixed-script and genuinely
different source families remain representable without merging coloured runs.

New tasks use font-workflow-1.37.4. Ordinary font hints no longer define binding
identity. Exact task/source requirements, source-intent revisions, true weight/
slant requirements and user locks remain authoritative. Candidate filtering and
binding share feasibility rules. Synthetic style requires its own evidenced
decision. A source-supported style group adopts one family while each span binds
its appropriate real face. No global font preset or page-majority assumption is
introduced; inferred photographic identity stays approximate.

Font packets visibly name their finite preparation step, batch and request IDs.
Source style, resource decisions, isolated glyph samples and family choice
precede binding. Related submissions apply atomically and return explicit
receipts. Exact acknowledged retries read the receipt. Native adoption remains
owned by the existing saved-file journal. Explicit old-task migration retains
old identities/history and cannot downgrade exact font requirements to hints.
Runtime comparison registrations survive detached pending ledgers and actual
submit/retry. Group revisions may span bounded packets; old faces stay unapplied
and block native adoption until every current group member is ready.

Source-line failures return legal source/native decision work. Unknown or
incompatible component states stop with a diagnostic instead of auto-evaluating.
Before construction, the actual writer's unsaved native emission is independently
decoded and checked against frozen line defaults, routes, topology and terminal
facts. This preflight does not replace saved-byte, render or final line gates.
An original-only forward run also exposed a missing correction exit between
source sealing and component binding. The binding packet now accepts bounded,
prior-hash source corrections with current observation/checkpoint identities;
the full original validators, obligations, bounds and observation history remain.
After sealing, a focused source decision can also correct its existing source
feature rows with exact prior hashes and then requires an explicit rebind. Real
open-shaft contacts use line_junction with original incidence and measured peer
geometry, without a hidden shape port or automatic-rerouting claim. Rejected
preflight reports remain registered hash-bound task dependencies.
Current component packets expose the current candidate's exact saved references
even before a selected baseline exists. Local compilation retains untouched
legacy nodes only when effective slots and bound resource identities agree;
real outside-scope font, resource or emphasis changes still require a grant.
Font discovery descriptors retain immutable project-local catalogue snapshots.
A render command with another backend configuration cannot replace a task's
font environment. Legacy shared-catalogue replacement triggers the normal
capability refresh; changed resource bytes and snapshot tampering stay blocked.
Font sizes quantize once to native hundredths of a point for ordinary text,
mixed-Math paragraph defaults and tables. This prevents the observed 18.15 pt
source intent from serializing as 18.14 pt through an intermediate EMU floor;
saved-size checks continue to read the native integer independently.

Line raster refinement retains the same fixed occupied source/render cells.
Exactly axis-aligned paired width chords can use rational cell intersections
instead of an irreducible half-source-pixel sampling floor. Every chord site
must correspond; missing sites, clipped support and unsupported directions
remain explicit. Source-to-render shaft coverage can refine its existing owned
cell set with finite interior sampling. Coarse inconclusive probes stay in the
report; valid failures and two-direction terminal/contact checks remain binding.

An independently saved, opaque polygon marker with no outline/effects now owns
its measured paint envelope. Its decoded vertices, actual fill and source anchor
bound the comparison plus the unchanged source tolerance and contact guard.
It no longer inherits a shaft-width multiplier intended for native line endings,
which had pulled unrelated text into marker checks. Other unqualified paint keeps
the conservative producer. Oversized/translated markers enlarge the measured
extent and still fail; internal fill and neighboring contact paint stay checked.
Separate marker anchors use their own saved vertices rather than substituting
the shaft endpoint. Previous full-crop differences remain retained under the old
producer; they are not relabeled as current marker PASS.

The 1.37.3 Windows verified font-stage resume, sharing-lock recovery, prior binding
hashes, scoped source grants, user locks and exact managed dependency reads remain
protected by regressions. Source workflow 1.35.2, design revision 8, execution
policy workflow-execution-1.37.0, verification policy evidence-checks-1.37.2,
native Math policy 1.35.3 and runtime resources 1.14.0 remain independent.

Both repositories use dev and 1.37.4; the formal source tag is v1.37.4. Unchanged
runtime assets and immutable complete-bundle parts are reused. Actual measured
results appear in the current validation receipts. Synthetic fixtures do not
accept external customer artwork; physical WPS/macOS require their own host
evidence. No token, speed or reconstruction-quality gain is claimed.

The customized active installation, user sources, private tasks/fonts/knowledge,
existing local edits, prior tags/assets and global skills are preserved. The
clean release source is an isolated maintenance checkout.
