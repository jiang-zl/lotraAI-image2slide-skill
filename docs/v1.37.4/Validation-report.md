# 1.37.4 validation scope

Current results must come from this release's final source and installed payload.
No historical receipt is relabeled. Focused font, migration, packet, state/route
and line-preflight regressions supplement the retained installation, native,
Math, Windows font sharing/recovery and final-delivery checks.

The release gate requires Windows and native Linux regression logs; actual
first/repeat installation and differential update; exact final parser/version/
ZIP checks; backend render/native save evidence; complete installed task export
and two-file delivery checks; independent original-only forward execution; and
public README/download/branch/tag/attachment verification after activation.

Prepared capabilities, package integrity, actual rendering/native behaviour and
whole-original acceptance are separate states. Physical WPS/macOS and external
customer artwork have no new qualification from synthetic fixtures. No provider
token or performance result is inferred from protocol tests.

349 executed and passed out of 350 discovered; the sole skip is the
Windows-only sharing test. Final metadata and archive checks
passed 2477 consistency checks and 70 actual final-file parser checks.

update and repeat. The update preserves 417 byte-identical managed files

and immutable archive identities are unchanged. The bundle reuses 18 immutable

receipts are completed after tag and channel activation.

Fresh installed task fixtures passed saved rendering, current visual review,
independent final gates, formal two-file export and exact-byte delivery checks on

production checks reject those divergences and all 24 explicit editable native
