# lotraAI Image2Slide 1.35.1

本补丁修复 1.35.0 静态审查发现的九处空间工作流问题，覆盖正常构建、保存后的
测量、局部修复、母件与实例、资格确认和独立最终验收。原生形状、填色和边框
继续优先；文字保持原生，公式保持真正 Office Math。

主要修改是统一空间构造与局部修订分派，持久化母件重新提取参数的决策，校验
被检对象与锚点归属，用完整逻辑/接触域检查居中和包含，收紧局部失效范围，
接入有限空间参数拟合、测量驱动的分阶段修复、稳定面拓扑，以及投影与单位
检查。完整调用链与九项对应依据见 Static-review.md。

新任务使用 workflow_version 1.35.1、source-features-1.35.1 和 spatial-1.35.1，
component design_revision 仍为 8。旧已绑定任务不自动迁移或重建；其旧策略
保留，使用新约束需要明确迁移。原图、用户 PPT、私有任务、字体、知识与全局
技能保持保留；新源码和分发包不包含本轮用户原图或私有任务数据。

本轮按用户要求只做实现和两轮源码/规则静态审查，没有运行测试、语法检查、
导入/CLI 检查、重建、渲染、Office 行为或性能/效果测量。发布与文件哈希只说明
源码和包的身份，不代表 runtime 或用户图像已经验收。未执行项没有计为通过。

runtime 二进制继续为独立版本 1.14.0，平台包、OCR/Math/字体等既有 runtime
资源引用和哈希保持不变。没有新 runtime Release，也不需要手动发布 runtime。
安装渠道 JSON 仅更新为新的 skill 目录和完整包清单。

分发包含小型 skill 更新包、平台安装入口及完整 bundle。完整包继续复用既有
不可变分片，只上传变化的源代码尾部分片和版本元数据。已发布 1.35.0 的标签、
提交和附件保持不变。实际发布结果、源码同步和包身份由本版回执另行记录。
