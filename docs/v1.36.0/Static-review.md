# 1.36.0 source review

Known Office-specific geometry constraints are checked beyond ZIP/XML validity.
Unbound arbitrary routes retain path, name/id, styles and arrow ends as unfilled
native shapes. Preset connectors retain actual ports. A non-preset route with
attached ports fails before mutation and requests an explicit valid route.
Builder, group bounds, both inspectors and independent final gates share the
same route descriptor. MC Choice/Fallback object IDs are mutually exclusive.

Application discovery is not qualification. Adapter identity includes application
resources/security context and actual fonts/code. Fixture and final-file evidence
are separate. Native jobs open unique owned copies, preserve canonical hashes,
check named descendants and OMML through save/reopen, close only their own
documents, never quit shared Office and have finite helper deadlines/logs.
Read-only export is separate from editing a saved owned copy. Native PDF failure
is retained before one auto fallback; explicit choices are never relabeled.

LibreOffice server, client and CLI paths use owned profile/temp directories,
without changing original binary labels, ACLs, global environment or security
settings. Actual nonempty PDF, page count and raster proof are required. Save
reopen uses a separate validation copy and cannot replace canonical OMML bytes.

Delivery root grants only new child output paths. Private source-relative guards
remain intact. Reservations handle collisions and interrupted resumes, cross-drive
exports stage on the target volume, and atomic publish refuses existing outputs.
Receipts and task references are rebound after publish. Two files remain public.
Every iteration must verify product/core and final-distribution consistency;
independent workflow/runtime versions and old task contracts remain explicit.
