# 1.35.4 installer review

Canonical templates contain exactly one optional API assignment, one primary
download condition, one API fallback and one optional API argument at the engine
call. Generation substitutes fixed tokens and writes only changed bytes; it never
rewrites previously generated source by matching a substring of its own output.
The standalone shell and local bundle coordinator use LF; shell Git attributes
override the inherited frozen-byte default. Windows entries keep compatible
PowerShell syntax and the host-owned utility-module import.

Final verification parses the actual distributed members, including the nested
skill payload in the complete bundle. It checks manifest/copy identities after
generation and checks immutable resource records against 1.35.3. Public source
and numeric version refs are checked before the stable channel is activated.
Runtime binaries, Math code, workflow policy and private user data are unchanged.
