# 1.37.1 packet hint and release validation

The patch adds 17 focused regression cases. Observation and binding use real
packet producers and bound templates. Recovery and final audit verify their
existing submit dispatch; terminal handlers are isolated to test routing without
inventing acceptance. Static literal packet kinds are all checked. Compaction
retains controls and rejects changed actions, arguments and template copy targets.
Structured arguments preserve paths with spaces; old bound policies stay unchanged.

The existing six regression groups plus the new group total 144 tests per host.
Current final installed payloads also run the self-authored two-region workflow
through native/render/final/export checks, repeat and differential installation,
exact final-attachment counterexamples, final shell/PowerShell ZIP parsing and
version consistency. Published README/download commands are checked after release.

Large immutable archives may use verified caches. New payload/part downloads are
checked publicly. Windows PowerPoint and Linux LibreOffice evidence is scoped to
those actual hosts/fixtures; Linux runs in WSL2 native project directories. WPS,
physical macOS, external complex artwork, third-party harness behavior and token
savings remain unqualified by these checks. Preserve all user files/local changes.
