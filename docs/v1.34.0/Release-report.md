# lotraAI Image2Slide 1.34.0

Based on the published 1.33.0 source. Component schema remains
component-protocol-1.32.0 / design_revision 8; new contracts use
workflow_version 1.34.0. Runtime binary version remains 1.14.0.

## Resulting behavior

A reconstruction now observes the unchanged original before selecting native
owners. It records recursive semantic units, located visible features,
observability, decomposition stops and representation requirements. A separate
feature inventory prevents an owner list from becoming its own definition of
completeness. Source relations continue through the existing relation graph.

Each original feature maps to native owners. Every native paint leaf needs a
source correspondence. Capability preflight checks actual types, geometry,
materials and registered construction outputs. Native presets with fill/outline
take priority, then compact composites/shared surfaces, then bounded native
paths or cubics. Higher tiers explain the source-supported limits of simpler
representations. Raster exceptions cannot silently satisfy schematic icon parts.

Existing native tables keep structured cells: text correspondences select an
actual row/column and exact source literal. Every populated native cell needs
its own text feature; a single table owner cannot hide its cell obligations.

Source-declared constructors add prisms, extruded contours, elliptic solids,
annular sectors, explicit ellipse levels, variable-width bands and projected
planar details. Faces share vertices/curves; inner walls, visible spans, edges,
paint order and material fills are explicit. Full annular holes use separate
opposite-winding subpaths, avoiding a stroked radial bridge. Independent band
boundaries preserve varying width. Unsupported or ambiguous geometry returns
a representation/source decision rather than invented hidden structure.

The current model interprets meaning, visibility and ambiguity and selects the
representation. Programs sample/fit numerical parameters, compile native
geometry, execute finite actions and verify actual saved results. Fixed versus
tunable is not a semantic-confidence claim. A single view does not establish
true hidden three-dimensional anatomy.

## Qualification and repair

Source basis, saved native consistency and actual appearance are separate
channels. Assemblies/instances require located checks of every required current
feature. Optional, pre-frozen executable probes cover orientation, ellipse and
thickness ratios, junctions, holes, variable band width, material colors,
lightness order, gradient profiles and missing local features. Invalid support
never becomes a passing zero. Same source coordinates are used without
candidate-specific registration.

Final visual review retains the existing whole-page dimensions and adds a
complete original-to-output feature review plus omission checks for every
original unit, independent of the native owner list. Edge diagnostics locate
suspicions; they do not prove semantic completeness. Final audit rechecks current
source, native/render evidence and declared feature probes.

Located failures are classified as source omission, inadequate representation,
parameter error, measurement invalidity, native mismatch, relation error or
source ambiguity. Scoped decisions/native journal application preserve unrelated
work, independent bests, locks and the existing original-problem budgets. A
source revision retains previous observations and requires located corrections
for removed/weakened requirements. No whole review runs after every local edit.

## Retained behavior and boundaries

The normal v1.33 function, shared-budget and private method lifecycle also applies
to v1.34 contracts. Surface methods capture source-free native geometry in
authored paint order; old source claims and qualification metadata do not
transfer. Old bound contracts retain their policy until explicit migration.
Native text, genuine OMML and Chinese/English font rules remain required.

One project-local skill is registered after runtime preparation. No Setup skill,
global skill update, model/provider key or cost/effect telemetry is added.
Private sources, tasks, fonts and personal knowledge are excluded from public
payloads. The dirty historical development checkout is preserved.

Validation scope, known platform limitations and artifact identities are in
[Validation-report.md](Validation-report.md). The public source release and
manually uploaded runtime assets have distinct publication states. The stable
installation branches activate only after the manual publisher verifies every
declared runtime resource.
