# 使用指南

[English](usage.md) · [README](../README.zh-CN.md)

## 整图重建

完整 bundle 安装完成后，打开工作项目，附上未经修改的参考图并提出请求：

~~~text
使用 $lotra-image2slide-skill，将这张参考图重建成可编辑 PowerPoint。
保留原文、公式、语义分组和连接关系；照片内容按其原有用途处理。
~~~

当前 agent 解释原图并判断语义。程序登记任务、给出当前行动合同、执行有限操作、检查保存结果与实际渲染，并管理验收。继续使用当前 agent，无需额外模型密钥。

## 局部修改

同时说明修改目标与保留范围：

~~~text
增大通信层与服务器层之间的间距。
保留公式、文字、图标部件及其他布局。
~~~

继续使用同一个项目和任务。已通过的属性与用户编辑按当前合同受到保护；修改影响到的依赖仍需检查。

## 中断后继续

在同一个项目中要求恢复已登记任务。保留原图及 `.lotraAI-build` 状态。安装后的 skill 说明了 `context-control resume`、`next` 与当前工作包的行动引用。新的原图登记为独立任务。

## 正式输出

重建工作流导出 `Final_editable.pptx` 与 `Report.md`，报告列出实际部件指标及方向。过程渲染、部件、检查点和临时 PDF 属于私有任务流程。正式通过的导出与中间 PPTX 分别记录。

三个[案例](examples/README.md)展示所提供的截图，当前没有配套原生 PPTX。实际 Office Math 结构、字体资源、原生编辑/保存/重开行为与整图质量，分别需要对应原生文件及宿主证据。
