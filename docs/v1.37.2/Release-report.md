# lotraAI Image2Slide 1.37.2

The baseline is published 1.37.1. New tasks bind evidence-checks-1.37.2:
independent source line contracts, program-compiled obligations, saved-native
route/style/contact/topology decoding, current per-line rendered evidence and
located, hash-bound source/render review. This prevents an aggregate dark-pixel
count or Scene-derived observation from substituting for actual line verification.

Line facts cover ordered straight/polyline/quadratic/cubic/arc routes, closed
paths and filled freeform arrows; both terminals, signed tangents, bends,
start/end markers, physical attachments, native connection IDs, stroke colour/
opacity/caps/joins/dashes/compound bands, crossing/shared/junction decisions and
source-confirmed occlusion. Saved decoding does not import the writer. Unknown
presets/effects and insufficient measurements retain an explicit decision; no
generic diagonal or bbox fallback receives PASS.

The program keeps all obligations while choosing the least expensive sufficient
method. A normal valid PASS stops optional refinement. Only inconclusive bounds
or support select denser finite local measurement. A valid failure cannot be
erased by switching algorithms or widening frozen bounds. Declared-only generic
metrics avoid unrelated SSIM/histogram/edge work. Exact-input raw facts and native
batch work are shared; independent final predicates are recomputed.

Every line has six criteria and current original/render crop references. Clear
cases share readable views across criteria. Non-PASS judgments create persistent
doubts even when no issue text was supplied. Every retained doubt needs enlarged
current evidence and explicit resolution plus the same program criterion's valid
PASS. Long/curved doubts are fully tiled. Measurement/visual uncertainty returns
to evidence review before drawing; established failures use scoped native repair.
Final delivery rejects missing gates, missing line rows/criteria, stale evidence
and wrong attachment bytes.

Independent forward testing exposed normal-flow defects: bent connectors did
not advertise actual corner capability; invalid-proposal deduplication omitted
the current implementation; one incremental template copied an object instead
of its component ID; and route repair copied geometry without its saved frame.
These are repaired with regressions. Invalid component.model types now receive
a located ValueError. Real rendered evidence also exposed shaft/marker overlap
and overly loose pixel bounds. Shaft ownership is corrected; finite cell-union
refinement tightens the same raster target, with complete interior coverage.
Justified higher-resolution rendering is bounded and retains the old evidence.
Program doubts persist as soon as issued and require explicit closure even when
a subsequent measurement passes. No source threshold was widened to pass.
The actual Linux native-arrow repair exposed a further rebind gap: rebuilding
the construction ledger omitted existing line obligations. Rebind now preserves
all doubts and consumed precision history; changed evidence reopens old resolved
questions while preserving their prior resolutions. Independent real-bind tests
verify this, including that empty applicability cannot erase outstanding doubts.
The final counterexample also proves that reordered self-intersecting curved
loops can have identical occupied sets/length; these now require ordered proof
or source-declared simple parts and never receive an insufficient PASS. After
an implementation update, an old visual manifest returns a current review packet
while preserving evidence/issues; it neither crashes next nor reuses old PASS.

Actual renderer calibration retains a material backend difference: PowerPoint
agrees with all 24 frozen bent-preset variants; LibreOffice agrees with 10 and
diverges on 14. The current production per-line render gate rejects all 14 with
valid failure evidence. The raw failed preset report remains FAIL. Encoding the
same frozen routes as editable native explicit paths passes all 24 per-case
native/paint bounds on both backends, without changing the original or 2.5px
calibration bound. This qualifies the representation and rejection behavior,
not universal LibreOffice preset compatibility or automatic rerouting.

Product/core/package/installer version is 1.37.2. Execution policy 1.37.0,
source workflow 1.35.2, design revision 8, Math policy 1.35.3 and runtime/companion
1.14.0 remain independent. Existing bound tasks are not silently migrated. Runtime
binaries/resources and unchanged immutable bundle parts are reused. The active
customized installation, user originals, private tasks/fonts/knowledge, global
skills and published history are preserved.

The evidence is scoped to actual recorded Windows PowerPoint and WSL/Linux
LibreOffice fixtures. It does not accept the lost erroneous artwork, arbitrary
external artwork, physical WPS/macOS or every third-party harness. Artifact hashes
bind identity and coverage; they cannot prove an observer looked or isolate an
editable local host. No provider-token or universal performance claim is made.
