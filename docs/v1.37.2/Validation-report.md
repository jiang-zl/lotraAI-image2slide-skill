# 1.37.2 validation scope

Current status: VALIDATED_FOR_RECORDED_HOSTS_AND_FIXTURES.

The exact test counts, byte identities, installed-runtime scope and outcomes are
recorded in Validation-summary.json and the release's machine-readable checks.
New focused tests independently specify original geometry and saved XML; they
cover equal-endpoint/bbox/length opposite elbows, short arms, reversed markers,
signed tangents, transforms, curves/arcs/closed/filled routes, dashed and compound
strokes, targets/topology, unsupported/invalid measurements, missing/stale crop
evidence, retained doubt closure, report completeness and actual method selection.
Lazy metric results must equal the demanded legacy producer values.
An additional explicit DrawingML fixture checks bentConnector2/3/4/5 across
24 declared rotation/flip cases per available renderer. Independent saved
vertices and actual per-case painted distances are both required; aggregate
page statistics cannot qualify this conformance test.
PowerPoint has 24 agreements. LibreOffice has 10 agreements and 14 raw failures;
all 14 are rejected by the actual installed production render checker. The raw
FAIL report is preserved. A separate qualification checks the same 24 frozen
routes encoded by the existing editable native path constructor on both hosts;
all native/paint comparisons pass under the unchanged 2.5-source-pixel bound.
Calibration scope is separate from full semantic task acceptance and does not
qualify automatic connector rerouting or every preset/pose in either renderer.

The independent forward task exercises the real next/submit path on a separate
original. Final installed Windows/Linux fixtures exercise source/bind closure,
native construction, actual rendering, final review/audit, formal export, exact
attachment verification and delivery counterexamples. Installation validation
covers first/repeat bundle and README commands, prior-to-current differential
updates, local-edit/unmanaged-file preservation, full-bundle download/repeat and
the final ZIP/nested payload/version/parser checks. Public commands and asset
bytes are checked after publication before final completion is reported.

Verified immutable archives may be preseeded; current new payloads/tail parts and
public entries are verified through their actual transport. Windows PowerPoint
and WSL2 native-filesystem LibreOffice are separate real-host scopes. Physical
WPS/macOS, external complex artwork, provider tokens and external harness behavior
are not qualified by these fixtures. Failed sandbox/backend attempts are retained
separately and are not counted as PASS.
