# 1.37.2 implementation and call-chain review

start sets a separately versioned verification policy. Source sealing validates
line facts before native ownership. Binding compiles the exact line/owner census
and all six criteria; callers cannot override the compiled policy. Old tasks keep
their original policy. Required source corrections retain hashes/evidence and
cannot widen limits or broaden measurement intervals.

component_workflow.evaluate runs independent native line checks for automatic
fixed-parameter qualification as well as program_checks. Native batches share
work across selected components. line_geometry decodes saved DrawingML with all
ancestor transforms and independent bent-preset definitions; ordered corners,
signed terminal tangents, length and both-direction bounds reject route aliases.
Closed/intermediate native markers cannot hide outside endpoint checks. Physical
contacts and real native connector references use actual target owners. Opaque
occluders must geometrically cover their source-declared interval and paint later.

line_verification verifies the source/native census and current actual-render
receipt. It checks every segment and owned source shaft pixel, paired original/
render normal widths, compound bands, dash phase/pattern and both-direction
terminal paint. Pixel/approximation error remains explicit. Raw decode facts may
share a command scope; numeric PASS is not persisted for independent final gates.
Normal valid failure never selects refinement; only INVALID may refine finitely.

Final packets prepare immutable crop/report manifests. line_review validates the
complete criterion/view/reference set and every byte hash, retains doubts across
revisions, requires enlarged current resolutions and rejects text waivers. A
resolution can be revalidated idempotently at final audit. component_final reads
current saved bytes again; workflow_delivery checks the exact gate and per-line
criterion sets and final attachment bytes. Zero-line applicability has a positive
source/native census. Missing/excluded/invalid checks are not PASS.

Forward testing used an independent observer with an original bitmap and the
skill, without intended output geometry or suspected defects. Its raw task and
failure evidence remain private. Source and package tests distinguish helper
fixtures, actual normal task progress, real host rendering, official export and
external artwork acceptance. Release gates require actual final-byte and installed
host evidence before publication; historical receipts cannot qualify 1.37.2.
