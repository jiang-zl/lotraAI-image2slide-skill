# lotraAI Image2Slide 1.37.3

This maintenance release fixes font revisions that could remain blocked after a
valid component source repair, Windows font-package commit recovery, and saved
run/cell font verification. The product remains a self-contained project skill.

An existing font revision packet now names its exact owner, location and script,
the prior binding hash, source font field and current authority or blocker.
Whole-owner authority covers that owner's font revision; a physical text-body
write alone does not grant unrelated font changes. Existing user locks and exact
font requests remain authoritative. A located evidenced redecision retains the
unapplied plan and returns affected owners to source work. Binding decisions stay
detached until the established native journal saves the actual file.

Direct EOT and provider font stages retain their owner, input, binding and staged
byte identities. Source, output and verification ZIP handles close before replace.
A Windows sharing lock retains the verified stage and unchanged input. Recovery
continues that commit and its saved build instead of reconstructing geometry or
spending another native-construction attempt. Changed or unregistered files are
retained as conflicts. Commit retries have a finite budget. Completed replacement
can resume after interruption before the next caller journal transition.

Saved binding checks resolve owner/location/script to each actual run or populated
table cell and verify its literal and font slot, including mixed Office Math.
Swapping two families within one owner no longer satisfies the binding gate.

Product 1.37.3 retains source workflow 1.35.2, design revision 8, execution policy
workflow-execution-1.37.0, verification policy evidence-checks-1.37.2, native Math
policy 1.35.3 and runtime resources 1.14.0. No new runtime binary release is needed.
Both repositories use dev and 1.37.3; the formal source tag is v1.37.3. Existing
immutable runtime assets and unchanged bundle parts are reused.

Validation includes current Windows/Linux regressions, real Windows file sharing,
current installed-payload task/delivery fixtures, installation first/repeat and
download/README gates, final ZIP/nested-payload version and parser checks. Exact
counts and results are recorded in the accompanying current validation receipts.
Synthetic fixtures do not accept an external original. Physical WPS/macOS need
their own host evidence. No token, speed or reconstruction quality gain is claimed.

The existing customized active 1.35.3 installation, original images/PPTs, private
tasks/fonts/knowledge, local edits, prior tags/assets and global skills are retained.
Clean published source is the isolated development-v1.37.3/source checkout.


Current bounded managed reads now deliver the exact child dependencies returned
by an already authorized frozen parent. This closes source Scene and line
measurement reads needed by normal repair/font workflows. Only the selected
page's verified same-task/source resources gain a lease; unselected siblings,
stale/changed bytes, another original and task-escaping paths remain rejected.
Five focused regressions cover this delivery boundary and its cache behavior.
Constructor/acceptance rules, implementation-bound native results and quality
thresholds are unchanged by this read-delivery repair.
