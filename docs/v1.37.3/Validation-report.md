# 1.37.3 validation scope

The new font regression suite covers legal whole-owner and exact run revisions,
rejection of text-only authority, current prior hashes, user locks, detached
bindings, batch failure, evidenced source redecision, real editable font data,
Windows file locks, preserved owned stages, exact commit resume, changed/unknown
files, finite retries and interrupted completed commits. Saved checks cover
individual runs, mixed scripts, multiline text, table cells and Office Math.

Windows executes the actual sharing-lock counterexample. Linux runs the portable
commit-conflict and run/binding checks; the Windows-only sharing test is explicitly
skipped on Linux, never represented as physical Linux/Windows host equivalence.
Current aggregate regression logs and final installed-payload receipts supply
the actual counts. Historical receipts do not qualify this patch.

Publication requires current source/runtime metadata, final archives and embedded
skill payload, parser and idempotent-generator checks, Windows/Linux first/repeat
bundle and README installation, differential update, complete download validation,
registered positive task loop/formal export and exact-byte delivery counterexamples.
Actual local backend fixtures are kept distinct from installation readiness and
external artwork acceptance. Physical WPS/macOS qualification remains pending.


Current bounded managed reads now deliver the exact child dependencies returned
by an already authorized frozen parent. This closes source Scene and line
measurement reads needed by normal repair/font workflows. Only the selected
page's verified same-task/source resources gain a lease; unselected siblings,
stale/changed bytes, another original and task-escaping paths remain rejected.
Five focused regressions cover this delivery boundary and its cache behavior.
Constructor/acceptance rules, implementation-bound native results and quality
thresholds are unchanged by this read-delivery repair.
