# lotraAI Image2Slide 1.35.0

This source release integrates spatial semantics through original recognition,
recursive decomposition, native construction, saved-native measurement, scoped
repair and independent final acceptance. Native shapes, fills and outlines keep
priority. Planar, face-attached, solid and mixed units use explicit reference
frames; 3D pose is source-supported and evaluated through observable projection.

Face-local aggregate centering, standing-object base contacts, typed support,
shared edges, occlusion, qualified local-constructor reprojection and spatial
review are normal-flow contracts. Independent original landmark pixels prevent
the generated projection from becoming its own ground truth. Unknown hidden
3D structure remains outside any verified conclusion.

Based on the selected published 1.34.0 source. Existing contracts remain bound to
their policy until explicit migration. Private tasks, user original images/PPTs,
retained deliverables, fonts/knowledge, global skills and Git history are preserved.

User exclusions: no tests, syntax/import/CLI checks, reconstruction, actual
rendering, Office behavior checks or effect/performance measurements. The release
status is IMPLEMENTED_STATICALLY_REVIEWED_PUBLISHED_UNTESTED once publication
receipts confirm public availability. Historical receipts are not v1.35 evidence.

Runtime binaries remain 1.14.0; no runtime resource or dependency is added.
Existing immutable runtime URLs and hashes are retained. Only skill/installer
catalog metadata and installation channel pointers change. No v1.35 runtime
tag or binary release is required. The complete bundle and small update remain
available; unchanged complete-bundle byte ranges reuse published v1.34 parts.

Detailed implementation mapping: Static-review.md. Publication receipts record
source commit/tag, exact assets and active channel separately from installation
and behavioral acceptance.
