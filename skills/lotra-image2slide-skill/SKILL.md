# lotraAI Image2Slide v1.31.0

## v1.31 scope override: text, primitive shapes and formulas only

Read [the v1.31 native core contract](references/native-core-v131.md) before
constructing standalone text, primitive shapes or equations. Bind source-read
parameters with `native-core bind`; construct from its frozen scene. Native
content, actual font/size/weight/colour, geometry and genuine OMML replace pixel
F1/foreground/edge/density acceptance for those explicitly bound owners. Font
sizes round half-up to 0.5 pt. Freeze body before placement; passed attributes
remain locked; three distinct candidates per phase is a hard stop for a source
decision, never permission to lower quality. Final layout/visibility remains.

All other v1.30 behavior below is preserved. In particular, complex icon
construction, all child parts, HD checks, qualified mothers and repeated icon
instance reuse are unchanged. Do not rebuild a qualified repeated icon from
scratch. Do not enroll an icon's primitive/text descendants in native-core.
Table cells, connectors, plots, curves, scenes and photos keep their old paths.
The broad experimental state-machine/adaptive scheduling draft is not released.

Formulas stay native structured Office Math in PPTX. `formula-render` uses the
bundled cross-platform LibreOffice Math equation editor on a private rendering
copy; it never replaces the delivered formula with ordinary text or an image.
Its receipt proves alternate rendering only, not Microsoft Office edit/reopen.
This additive equation route does not change the existing icon renderer.

Release validation status: NOT_RUN_PER_USER_REQUEST. Earlier broad-draft tests
do not certify this scoped release. This scope override takes precedence over
the inherited raster typography rules only for explicitly bound owners.
