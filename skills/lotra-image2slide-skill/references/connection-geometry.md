# Original connection graph, visible paths and physical ports

v1.17 uses two separate inputs: independently observed original connections,
and the actual saved native inventory. Wrong output slopes never suppress an
original candidate. A caption or endpoint marker is not required for a line.

`connection-geometry TASK survey --out PACKET.json` issues original-only child
views and CPU LSD proposals. Classify each source recursive region as
connections, no_connections or delegated. Raw LSD detects strokes, not semantic
objects: text, icon decoration, table rules, curves and scientific edges must
be interpreted through these original regions. The model interprets; it never
executes drawing commands from prose.

`connection-geometry TASK observe-source --request OBSERVATION.json --out
RECEIPT.json` freezes source_hash, source_recursion_hash, region_coverage,
parts and texts. Each part has a unique id, original region/ROI, kind, color,
source endpoint landmarks, shaft fit_rois and both marker visibility states.
Straight shafts are fitted from original ink with robust TLS. Endpoint tips or
marker centers are independent landmarks and are not moved by a shaft fit.
Curves carry original linear/quadratic/cubic function controls. A filled bent
polygon can locate terminals by its source-supported polygon vertices or the
midpoint of a closing edge. Confirmed none differs from hidden and uncertain;
unresolved terminal marks require another source observation before freezing.

`discover` returns retained original segment–occluder–segment candidates.
Both strokes must lie near opposite sides of the original text/container.
Direction cross product, extension offset, style, source blur and optional
marks are separate evidence fields. No head/tail complement is necessary.
Every candidate receives an explicit same_straight, same_curve, independent
or branch decision with located evidence. Rejecting a candidate as independent
requires specific distinguishing original facts. Geometry does not decide
semantic meaning and the output is never evidence for an original rejection.

`bind` compiles source_graph, items and candidate_decisions. Each original
primitive maps once to a saved fragment; every saved connector and preset
line maps once to an original primitive. Original set equality and native set
equality are independent checks. Canonical straight coordinates and expected
marks are derived by the program, never supplied as final drawing coordinates.
Logical paths own visible fragments. Interior occlusion cuts bind the actual
text owner, have no terminal marker, and are not free endpoints. A common path
has two true terminals; each intermediate occluder contributes two cuts.
Unmarked, one-marked and two-marked paths use the same procedure.

A true terminal separates semantic_owner, physical target and contact profile.
The physical target must be the actual child contour, not its group's frame.
Profiles are boundary_touch, marker_center_on_boundary, circle_half_embedded,
intentional_gap, inside_port, or free. Original rect/ellipse/polygon contours
are explicit observations; fitted_ellipse measures original black outer ink,
including rotation. The program calculates original signed distances and gap
intervals. A source gap must exceed the 2 px original uncertainty to qualify as
intentional. This source uncertainty is separate from saved execution precision.
A free terminal needs a specific context (legend, axis, timeline, annotation,
standalone layer indicator or original_detached) and actual endpoint/mark checks.
Generic evidence or default free/independent does not close a contract.

The registered connector_geometry repair operator executes through the same
immutable recursive repair plan as other constructors. It fixes one canonical
axis, trims cuts to actual text rectangles and checks direction and offset.
The union of actual fragments must cover the visible common path; alignment
alone is insufficient. Source-observed gaps retain their measured separation.
A deliberately separated axis may miss the target contour: the gap operator
keeps the source axis and solves the actual distance without inventing contact.
Scientific circle-to-circle edges may explicitly use between_physical_ports;
the program computes their common axis from actual owner centroids and their
radial intersections. It cannot infer that normalization for arbitrary arrows.
When two contour intersections have the same distance to a target centroid,
the program selects the one facing the opposite terminal. Boundary contact
also requires the straight shaft's intersection with the target interior to
be at most 0.2 source px; touching the far contour while crossing the node is
a failure. The targeted saved-native check runs before a new drawing is adopted.

Explicit binary scientific edges retain distinct original terminal sets.
Their crossings are recorded as crossings, not silently joined. A proposed
edge/nonincident-node overlap needs actual isolated black/white owner paint:
zero shared painted pixels at 4x sampling closes a false box overlap; real
intrusion stays unresolved. These decisions use compiled original topology
and saved geometry, without accepting a generic unrelated declaration.

Native straight connectors bind to nonpainted custom connection sites placed
in the physical owner's semantic group. These sites have no fill, no stroke,
unique stable native IDs and source-graph metadata. A saved terminal checks the
actual stCxn/endCxn id/index, port center, owner ancestry and actual contour/gap.
Moving the containing semantic group moves the port; moving an individual child
requires a new contour check and program redocking. Native XML binding is not
a universal claim about every Office editing scenario. Filled polygon arrows
receive actual geometry/semantic association checks and never masquerade as
native p:cxnSp binding. Horizontal/vertical preset arrow axes have a bounded
constructor; a curve, bent polygon or branch uses its explicit source function
constructor rather than a straight substitution.

Boundary contact tolerates 0.2 source px serialization error; common-line
extension offset tolerates 0.15 px and direction cross product 0.002. These are
execution precision, not permission to change original facts. A circular half
embedded marker must be a real editable native circle; actual area overlap is
0.46–0.54 and its measured center must agree with the line endpoint. A symmetric
DrawingML diamond may use source-supported marker_center_on_boundary. It is not
treated as a circular marker, and its center contact is not an area-overlap
claim. Unsupported actual topology remains an explicit failed obligation.

The transaction preserves native IDs, unrelated node XML, group transforms,
fonts and package resources, and replays the exact original-derived constructor.
Every original primitive, decision, logical path, true terminal and generated
nonpainted port appears in recursive obligations. Parents cannot close with a
missing child or stale receipt. The source graph hash participates in the
execution basis; both preconstruction and whole-quality routes issue missing
or stale source packets, even when a legacy connection contract already exists.
Actual PowerPoint rendering and the entire quality loop remain mandatory.

An `independent` rejection requires typed, program-verifiable distinguishing
facts: original colour/style difference, distinct frozen semantic relations,
or a visible terminal marker on the text-facing endpoint. Boilerplate reasons
cannot remove a retained source candidate. Branches require located original
junctions and equality of their observed arms and compiled interior cuts.
Curve controls come from the frozen original functions; contradictory caller
controls or a straight substitute are rejected.

For source corrections, coordinate boxes alone do not bound arrowheads, line
strokes or effects. `composition capture` creates four pages containing only
the exact replayed owners from the immediate before/after constructor snapshots, on black and
white backdrops. The same actual renderer measures their paint support, with
the fixed two-source-pixel edge margin. Every pixel outside the program-owned
frames and measured paint support must remain identical. The constructor,
native ownership, resources, page files and renderer receipts are reverified;
the host cannot submit a permission mask. Missing paint support is a work
packet, not an assumed pass.
Historical finite constructors carry a version. Exact replay verifies their
bounded change scope; the current geometry and whole recursive checks still
decide acceptance. Replaying an older constructor cannot waive a new failure.
Prior source corrections must independently pass their own constructor and
pixel protection before the current connection guard succeeds. This preserves
the full causal chain when an earlier correction legitimately replaced media.
The final mask is the union of individually verified actual paint support at
every retained connection stage. Each stage uses the same fixed margin once;
the margin is never enlarged as the chain grows. An absent prior receipt or a
cycle blocks closure. This retains the original arrowhead footprint even when
a later repair changes the same connection again.
Native measurement copies retain external shape connection sites and parent
transforms, while making those dependencies unpainted. Their exact saved XML
and ancestor frames enter the capture identity; dependency geometry changes
invalidate the matte. No additional painted owner is added to the permission
mask, and the delivery deck is not changed by this isolation step.

When a frozen connection maps to a filled-arrow alignment participant, its
original colour component supplies numeric source bounds for a straight
horizontal or vertical filled arrow. Programs retain the
raw earlier bounds/interval and the same tolerance width, derive signed source
anchor offset from original pixels, and expose that derivation in the layout
report. Source measurement correction never uses the candidate to redefine the
original and never mutates the frozen source specification.
Raw historical source values remain available only for replaying their exact
sealed constructor. Current layout checks always use the independently derived
source measurement. Bent arrows retain their explicit original path geometry.

When a previously coarse rectangle/ellipse port has one independently frozen
original feature function, connection binding recompiles that physical boundary
from the original function, preserves the earlier contract, and recalculates
the original tip-to-boundary interval with the same fixed uncertainty. It never
uses the rendered owner to train the interval. The function identity enters
`source_function_boundary`; later changes make that connection evidence stale.
Ambiguous or unsupported oriented/curved bodies retain their original contour
route and require original reobservation rather than silent box substitution.

Historical native replay loads its own immutable retained connection contract;
it must not be reconstructed with a later corrected boundary. The current
connection report separately checks the latest original function, end profiles
and saved physical attachment. Historical replay proves what was executed and
preserved, while current quality proves whether the present result is correct.
