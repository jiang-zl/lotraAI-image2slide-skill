# Source-relative distance and inline-math quality

For a new containment contract, declare `target.center: directional_clearance`.
The program measures how far the complete painted content can move toward each
effective boundary before first contact. Horizontal/vertical centering balances
these distances, including stroke, glyphs and every direct semantic member.
Source-supported intentional asymmetry uses frozen `target_asymmetry_px: [x,y]`;
zero means the user-authorized centered target. Never derive an original target
from a defective output, widen a failed tolerance, or replace the body by a group
frame. Overflow routes bounded size/layout repair before distance balancing.
Historical center contracts remain historical; amend from independent source
evidence before using the new predicate.

Preserve source text flows. Related prose and its inline mathematics use the
same native textbox and ordered paragraph; one genuine OMML zone per span.
Standalone mathematical operators inside circles, matrices, legends or separate
diagram nodes retain that source-supported ownership. Semantic association alone
does not merge distinct objects. `typography` on a math owner/span supports finite
`font_size_pt`, exact `font_family`, boolean `bold`/`italic` and RGB `color`.
Serialized typography, source AST/prose, actual editable behavior and rendered
placement are individually checked. Font-family changes still need the existing
resource identity/portability contract.

`office-math roundtrip-probe` is the deterministic headless alternative to
`edit-probe`. It changes every real OMML span on an owned audit copy, saves that
copy through actual PowerPoint, and independently reparses every changed span
and unchanged prose. Report the exact method. This proves native programmatic
editing and Office persistence; it does not claim GUI editor interaction.

Original black strokes can be gray after antialiasing/downsampling. Measure
full-shaft support as well as fitting residuals. Straight TLS requires at least
0.55 interior-bin coverage; the constrained gentle quadratic family requires
0.60 coverage and at most 2 source-pixel RMS. These are initial pixel-support
gates for this fitter, not semantic similarity thresholds for all curves.
Unsupported curvature/insufficient evidence returns a reobservation packet or
a richer registered fitter. A short well-fitted arrowhead cannot establish the
whole curve. Source-associated labels get local-tangent clearance constraints;
ambiguous text-envelope collisions require actual owner glyph mattes.

Native elbow connectors use actual Office presets/handles. Native Bezier
freeforms retain edit-points and arrow styles; physical attachment is checked,
but automatic Office connector binding is not claimed for freeforms. A failed
actual export preserves its receipt and permits exact rollback to an already
rendered baseline. Never accept a numerical-only construction after export fails.

For every source-associated connector, use `source-connections` and the existing
finite `connection-geometry` action. Bind the true physical contour, classify
contact/intentional gap from the original, preserve terminal roles through node
movement, and recheck actual saved attachments. For spacing/overlap, populate the
whole original role inventory and use the existing all-neighbor closure; its
independent all-pair audit cannot be replaced by a few reported examples.

Run the unique whole-quality loop after actual rendering. A helper file or
specialized geometry/math pass cannot close unrelated semantic, source, layer,
connection or native-edit obligations. Execute the next feasible source/repair
packet and preserve failed strategy evidence. Final task reports stay concise,
while current detailed evidence remains in the owned runtime directory.
