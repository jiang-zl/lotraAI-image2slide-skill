# Independent object convergence and global aesthetics — v1.18.0

The two mandatory final gates are `object_convergence` and `global_aesthetic`.
They run in `quality-loop audit/run/export` and in the shared acceptance path.
An old accepted stage, a root review or a helper export cannot satisfy them.

## Frozen source plan and independent global score

`global-quality discover/bind` presents the original and compiles source-bound
regions, intentional layout, alignment/spacing groups, style groups and reading
hierarchy. Original observations and authorized aesthetic targets are separate.
Weights, normalization, tolerance and floors are frozen in the plan and retain
revision history. They cannot be changed to make a failed candidate pass.

After every composition, `global-quality observe` binds six actual whole-image
observations to the original hash, saved PPTX, actual preview, source plan and
implementation. The model supplies located observations and ordinal severity;
programs compute scores. Levels mean: 0 major structural defect, 1 repair needed,
2 acceptable with a stated minor limitation, 3 no located defect in the stated
dimension. This is a rubric, not a calibrated probability. Missing is null and
blocks acceptance. Numeric sub-metrics remain visible separately.

The dimensions are layout (source region center and proportions), balance
(contrast-mass center, quadrants and whitespace relative to the source's
intentional asymmetry), alignment/spacing (declared groups), layer/occlusion
(all current structural/connector gates plus observation), color/style (global
histogram plus same-family line widths and source style observation), readability
(exact text/math and current source hierarchy observation). Local SSIM/PSNR and
icon metrics are not included in this global weighted sum. No global score can
compensate wrong content, missing parts, topology, connections or editability.

`global-quality optimize` accepts only registered owners, finite operation names
and bounded budgets; it computes coordinates. It supports translation, uniform
scale, alignment/spacing and source-declared paint-order restoration. It does
not accept arbitrary coordinates, XML, formulas, text or icon path generation.
Every transaction is replayable against immutable before/after native bytes and
resources, invalidates affected observations, requires actual rerender and reruns
the complete loop. A color/anatomy/content failure returns to its local object
loop; global layout is not allowed to conceal it. Infeasible constraints return
located reasons and retain the previous candidate. Two ineffective attempts prune
that action branch without accepting an unresolved failure. The stable strategy
key excludes filenames, revisions and budgets. An outstanding reflection or
ineffective transaction must close before any different strategy can execute;
ancestor transaction debts remain in final closure. `global-quality rollback`
restores the exact pre-layout composition and preserves earlier local gains.

## Independent exhaustive object lifecycle

Program inventory is the union of original quality units, every quality policy,
every actual saved native owner (including groups and derived ports), and native
table cells. A model cannot submit a shortened coverage list. Each unit owns
candidate records, its purpose-specific vector, hard-result dependencies,
`best_local`, `best_in_context`, comparison outcome and convergence/locks.
Immutable shared artifact references avoid duplicating an entire PPTX per part.

Every current unit is checked before ranking. Parent/group closure depends on
the actual children; nonpaint groups/ports use structural checks, with pixel
metrics explicitly inapplicable. A first reconstruction without an approved
baseline cannot treat painted descendants as structural-only: `object-loop
discover-source/bind-source` freezes each owner's original ROI/features/view,
and `object-loop observations/observe` requires its own actual candidate-view
observation. Every painted owner is measured independently. Tiny units with
inapplicable SSIM retain their
measured native/content predicates; missing required metrics still block.
Objects from incompatible policy/semantic/context revisions are never compared
as if they shared a ruler. Previous histories survive a revision or external
edit; current evidence must be re-established. Each individual original binding
is included in the affected unit's measurement-profile identity. A corrected
source window retains previous profile bests and history, starts a rechecked
current best, and cannot claim a cross-window numeric gain or regression.

A regression retains the previous unit best and produces a finite local rollback
or repair obligation. `object-loop rollback` restores only named recorded units
from their immutable best native payloads, checks dependencies and full resource
identity, then requires actual rendering and full context checks. Independent
improvements in unrelated objects remain intact. Unsafe cross-context restores
are rejected with a dependency diagnosis rather than overwriting other artwork.

Convergence means declared hard targets met, complete current evidence, current
context best retained and no regression/repair debt. It may occur on the first
adequate candidate. A failed or unmeasured unit never locks because a numeric
branch budget expired. Locks protect content, formula structure, icon anatomy
and paint; the explicitly authorized global program may change placement,
uniform scale and paint order while preserving intrinsic locks. Any other
change reopens its affected object and dependent context, with history retained.

## Result reporting

`Result.zh-CN.md` reports goals, the six dimension scores and their direction,
overall global threshold/floors, individual lifecycle status and actual renderer.
`Evidence/Global-aesthetic.json`, `Global-plan.json`, `Global-observations.json`
and `Object-lifecycle.json` provide the per-object and global structured facts,
failed checks, best candidates, revision history and locks. Counts describe
coverage only and are not quality scores or substitutes for the user's visual
acceptance. Final acceptance independently recomputes the exact object set and
verifies every current locked record and immutable result against the saved
PPTX, scene, preview, renderer, source plan and implementation. Changing a
caller-supplied pass field or retaining a receipt from an older run is rejected.

A no-gain global attempt requires rollback unless the program proves that its
complete saved native contents, placement, traversal paint order, font/media
resources and actual preview are exactly equal to its immediate predecessor.
Such an immutable `NO_NATIVE_OR_PAINT_CHANGE` receipt records that there was no
mutation to undo; it never claims a quality gain or permits local failures.
