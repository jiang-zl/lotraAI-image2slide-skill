# Program-owned original-region recursion

An evidenced ellipse with internal colour regions/roads can use `method.container_function`: `source_hash`, `source_evidence`, `preset: ellipse`, absolute `bbox`, `base_colour`, and `partitions[{id,points,colour,source_evidence,semantic_role}]`. The program clips every closed native fill polygon analytically to the ellipse, then draws one independent native outer outline. Task-specific coordinates stay in the source contract. Clipping alone does not certify content completeness.

For an existing native owner with missing internals or a wrong schematic waveform, `source-structure-repair TASK REQUEST --out RESULT` freezes original-only evidence, exact unit/view identities, implemented `container_function`/`signal_function` parameters and explicit source correspondence bounds **before** drawing. It uses the shared native candidate/commit/render path. The final guard replays the complete native commit and requires source appearance bounds, recursion and signal/content gates. Approved style protects unrelated objects; an incomplete old silhouette is never itself proof of correct restored content. Requests contain `source_hash`, `expected_baseline_sha256`, and `items[{unit,source_view,evidence,source_constraints,method}]`.

Use this reference for `source_recursion` packets and `source-recursion` commands. The original-region tree is independent of the candidate inventory. Every task activates its immutable source/policy binding, surveys the full source canvas in program-generated tiles, and schedules every declared component and every newly split child.

Interpret the original crop and its parent context. The program always crops the original file directly; display enlargement is not new evidence. Return one decision per named region with the actual original crop hash and located observed content. The program validates and commits a split transaction only after all children pass validation. Worklist ordering gives siblings attention before deep retries. Do not choose an arbitrary maximum semantic depth.

Actions are `split_semantic`, `split_drawing`, `reobserve`, `repair`, `propose_leaf`, and `review_partition`. A semantic whole can contain several drawing parts. Curve control points, individual pixels and continuous gradients are not automatically semantic children. A known complete component with defective geometry needs repair, not endless splitting.

A leaf proposal supplies a type (`primitive`, `continuous_curve`, `text`, `formula`, `table_cell`, `complete_media`, `verified_assembly`, `background`), complete representation bindings, required edit scope, visible-content explanation and no unexplained region. Internal critical content cannot end as a plain primitive/background. Complete media must satisfy the existing source-specific raster permission and editing contract. A bitmap selection or low source area is never a stop proof. Each critical visual feature maps named source parts or actual object IDs; mandatory native/content checks survive approved appearance policies.

Parent closure is a new observation of the actual parent source region after every child is ready. No parent `matched` result closes child policies automatically. In the saved-result check, source-ready nodes must have actual native bindings; all critical features are checked independently and failures propagate to the root. Independently declared interior structure has an additional source-structured/actual-uniform guard. Pixel statistics are diagnostic triggers, not a theorem of semantic completeness. Unresolved evidence and budgets remain pending.

Before interpreting a small child, inspect its own `original_view` and necessary context. Source tile surveys name all intersecting known components and locate genuine background/non-figure UI. Omitted structure is added as source children/parts; do not label unexamined regions background. Correcting source observations is explicit and versioned, never overwriting a previous evidence file.
