# Verified compact PPTX delivery

Every official exit (`quality-loop export`, agent runtime export, guarded legacy
finalize) exposes exactly `Final_editable.pptx` and `Report.md`. Report each
component's measured category metrics with ↑/↓ and actual size. PDF is validation
data. A draft retains its actual status; storage verification cannot promote it.

## Mandatory construction and resource coverage

Every new owned PPTX is compacted before fonts and actual rendering.
`candidate_cost` enumerates all OPC parts, saved native descendants, table cells,
image/preview/SVG relationships and shared fonts. SVG internal commands count
independently. Shared resources count once; logical owner lists are references,
not repeated byte costs. Persistence updates the hash-bound cost inventory.
Read located owners/resources, not an entire report into model context.

`delivery_size` independently reconciles every original resource name and hash
against a terminal result: optimized, evaluated without gain, unreachable,
exact alias, or signed immutable. Missing/duplicate rows, unknown results,
stale input and unproved resource changes block delivery. Cost thresholds locate
opportunities; they never waive semantic parts or impose a shape quota.

## Equivalent algorithms

- Closed integer SVG rectangles: relative move encoding preserves absolute
  coordinates, winding, closepoint and stroke. Unsupported curves retain their
  original bytes. No coordinate rounding.
- Filled cell regions: deterministic horizontal/vertical partitions with
  independent evenodd XOR coverage (including holes) and exact raster probes at
  1×/2×/4×. Stroke, stylesheets, effects, transforms and unsupported/large assets
  cannot enter this branch. Path ownership stays intact. Changed seams or
  antialias pixels reject the representation.
- PNG: lossless DEFLATE search preserves inflated scanlines and non-IDAT chunks.
  Eligible 8-bit RGB may map its existing <=256 colours to an exact palette,
  preserving RGBA samples, colour metadata and background. No quantization.
  Alpha/high-bit-depth/animation/unknown chunks keep an exact supported encoding
  or the original.
- ZIP: compare ordinary interoperable DEFLATE strategies under bounded CPU
  work. Remove only proved unreachable image parts and byte-identical aliases.
  Full editable fonts and all native text/formula/shape XML stay byte-identical.
  Signed packages retain the entire original archive.

Only a smaller actual PPTX can replace original storage. This route forbids
geometry simplification, photo colour reduction, raster substitution, preview
downsampling and font subsetting. Different clip windows remain separate unless
an exact constructor and actual host evidence permit sharing; rounding a native
crop is not lossless.

## Actual validation and PDF lifetime

Actually open/export the final optimized PPTX with the configured host. Reuse
an input render only if PPTX/PDF hashes, renderer, Office build and fonts match;
otherwise render it afresh. Compare all page/crop/media boxes, text, links,
outline, direct host preview pixels and vector-PDF raster pixels at 1×/2×/4×
(720/1440/2880 long-side pixels). Exact resource semantics protect finer geometry
in addition to these probes. Export errors, missing PDF, host drift and any
pixel difference block adoption. Exact native XML/full fonts preserve editing;
screenshots alone do not prove editability. Preserve prior acceptance scope:
storage equivalence is not a new whole-figure artistic approval.

`transient_export` registers owned PDF leases. Keep PDFs during recursion, HD,
font and quality checks. After all dependents and delivery verification pass,
release registered files inside their exact root; retain compact numerical
observations and hashes. Unregistered history/user PDFs stay protected.
Verified successful Office helper GUID staging is removed. Incomplete helpers
retain recovery data and never affect shared Office documents. Exceptions keep
bounded current diagnostic evidence until that branch is repaired.

A disposed comparator cannot stand in for a live PDF. New HD measurement
programmatically reexports its immutable PPTX, compares the retained host/page
fingerprints, then records a new lease. Changed evidence needs fresh quality
checks. Delivery verification uses final PPTX/report hashes and compact export
proof, without requiring a deleted PDF. Detailed failures/resources stay local.
