# Source operators: read the current route only

These operators propose executable local methods; source interpretation and saved-result acceptance remain in the normal loop. Store large requests/proposals on disk and retrieve the packet's bounded facts. Native objects, original crops, assets and programs are cached under .lotraAI-build in the user's project.
