# EX03 云形轮廓：关键弧段与自然路径

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 原图是可编辑云图标或有明确凹凸弧段的轮廓。

**exclude**: 真实云照片不套固定圆弧个数；极小不可辨起伏不假设为部件。

**decomposition**: 云对象 → 主要边界弧段与必要内部标签；渲染可使用单条原生路径。

**method**: 试用匹配的原生 cloud 预设；不匹配则以少量 Bézier 段构成闭合轮廓。

**parameters**: 关键地标、曲线控制点、闭合、平滑强度、描边；误差大的弧段局部可调。

**repair**: 顶部弧缺失时恢复对应分段或地标；不把整条云轮廓统一加强平滑。

**negative_example**: 整体 IoU 高就接受丢失的凹口；使用很多小圆拼出未经验证的外轮廓且难以编辑。

**validation**: 设计示例；路径与预设选择需依据实际源图验证。
