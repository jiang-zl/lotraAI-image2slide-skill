# EX08 跨组连接：端口与移动后的行为

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 节点间有方向关系，任务要求移动节点时连线保持正确。

**exclude**: 纯装饰曲线不必虚构逻辑连接；任意曲线不默认支持真实附着。

**decomposition**: 连接作为独立关系对象；节点可属于不同语义组。

**method**: 支持时使用真实 Connector 和端口；曲线几何与逻辑关系分别维护。

**parameters**: 连接端口、路线点、箭头大小、线宽；变换后的端点重新计算或验证。

**repair**: 方向错先修关系；仅贴近但不附着要修原生绑定；路径穿过文字修路由或层序。

**negative_example**: 把线贴到框边就算附着；移动父组后连线不动；把箭头头部删掉但中心线分数仍高。

**validation**: 设计示例；必须在实际 Office 文件副本上移动节点、保存重开验证。
