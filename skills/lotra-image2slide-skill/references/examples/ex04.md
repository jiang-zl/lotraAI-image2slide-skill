# EX04 城市背景：多类型递归拆分与向上验收

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 示意城市区域中有道路、建筑、车辆、文字和关系线等多个语义类。

**exclude**: 真实航拍或地理测量影像不能按装饰示意背景自由重构。

**decomposition**: 城市区域 → 地/天色块、道路、建筑群、车辆、植被、标注；建筑群再拆实例，各个组合子项按 EX01 的来源条件选择；纹理按 T11。

**method**: 底色原生形状，道路路径/形状，建筑和车各自重建，标注原生；叶子完成后逐层组装。

**parameters**: 区域局部坐标、道路接点、建筑/车变换、z-order、色块与纹理；跨区域端口独立。

**repair**: 道路断裂先查跨子项接点；车被吞掉查遮挡；子项位置都偏则修父变换；漏车先修观察/拆分。

**negative_example**: 整张背景放为大位图；所有子项都按 icon 指标；仅凭各裁片最高分宣布整个城市通过。

**validation**: 设计示例；没有真实城市图片、已完成 PPT 或实测评分。
