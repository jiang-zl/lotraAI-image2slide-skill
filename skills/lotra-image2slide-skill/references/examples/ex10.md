# EX10 曲线图：可见轨迹与原始数据的区别

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 有坐标轴、曲线/散点/柱和图例的科研图。

**exclude**: 纯连接曲线不要按数值数据图处理。

**decomposition**: 数据层、轴网格、图例、标注分别组织；图例与 series 绑定。

**method**: 有可信数据时原生图表优先；仅截图时可见轨迹与标注重建，说明精度范围。

**parameters**: 坐标映射、曲线节点、点位置、线型颜色、轴标签与图区域。

**repair**: 图例错修归属，峰值错修局部轨迹；没有原始数据时不反推精确数值为真。

**negative_example**: 重画一条看着合理的趋势线；把缺失误差棒当噪声去掉；声称可精确编辑原始实验数据。

**validation**: 设计示例；数值和外观编辑能力分别验证。
