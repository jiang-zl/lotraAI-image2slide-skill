# EX09 真实影像：数据忠实与表示例外

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 真实照片或实验影像，且任务允许其作为独立可替换影像保留。

**exclude**: 严格所有内容全矢量时不能直接接受；普通示意背景不借此保留大底图。

**decomposition**: 影像主体与所有可重建标注分别建模，避免裁片带入重复标注。

**method**: 保持影像内容，原生重建标注；记录可替换影像的明确范围。

**parameters**: 位置、crop、尺寸、已有显示参数；不得随意改变科学数据外观。

**repair**: 边界错修裁切，标注错修原生对象；不生成缺失实验像素。

**negative_example**: 为追求矢量率生成相似纹理替换实验图；或以“复杂背景”为名保留整页截图。

**validation**: 设计示例；必须结合实际任务的栅格许可与数据要求判断。
