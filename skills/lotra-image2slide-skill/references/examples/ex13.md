# EX13 交错遮挡：语义树与渲染树不同

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 不同对象相互穿插，或跨组线在不同区段有不同前后关系。

**exclude**: 普通简单组不需要无故拆成渲染碎片。

**decomposition**: 语义对象保持完整归属；必要时对应多个渲染片段及统一编辑映射。

**method**: 先检查简单原生分组能否表达，不能时显式分片并维护映射与操作行为。

**parameters**: z-order、裁切/分段边界、父子变换、连接路由。

**repair**: 局部遮挡错误修图层或分段；修后查对象整体移动与跨片连续性。

**negative_example**: 规定所有连线永远在对象下方；把渲染分片误记成多个科学对象；只验收语义树而不看实际合成。

**validation**: 设计示例；是否能满足原生整体编辑取决于实际实现并须验证。
