# EX06 文本与数学：小符号优先保护

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 含负号、下标、分式和文字标签的科研图。

**exclude**: 没有数学结构的纯文字不强制转换成公式对象。

**decomposition**: 文本段和数学 AST 分开；混合行保留基线和标签归属。

**method**: 普通字用原生文本，结构公式用可由目标编辑器修改的原生数学对象。

**parameters**: 数学 AST、字体、字号、基线、文本宽度；内容锁和布局锁分别维护。

**repair**: 少负号先修内容；字宽错先匹配字体；分式基线错只修数学排版并复查近邻。

**negative_example**: 负号漏掉但整体 SSIM 高而通过；用公式 SVG 或文字上下标冒充原生公式编辑。

**validation**: 设计示例；需要实际编辑公式、保存重开及渲染核对。
