# EX07 合并单元格表格：结构优先

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 包含行列关系或合并单元格的科研表格。

**exclude**: 仅视觉排列成网格的独立图标可能应按重复对象处理。

**decomposition**: 表 → 行列和跨行列单元格 → 原生文本/公式；存 cell ID。

**method**: 原生表格与真实合并结构优先，复杂内容按目标能力验证。

**parameters**: row/col/span、行高列宽、padding、边框和字体。

**repair**: 归属错先修单元格结构，再修布局；不能为了不溢出不断缩字。

**negative_example**: 规则字符串矩阵冒充合并表格；用一组线条看起来像表格就声称具备原生表格编辑。

**validation**: 设计示例；当前简单 table builder 的支持边界必须在实施时核对。
