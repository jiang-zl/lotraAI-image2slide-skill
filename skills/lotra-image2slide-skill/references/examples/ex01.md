# EX01 组合部件：来源分解与知识筛选

Status: design_example. This example contains no saved user geometry or quality pass.

**applies_to**: 当前原图中存在可辨识的外壳、内部部件和连接关系，需要原生部件编辑。

**decomposition**: 依据实际可见轮廓拆出外壳、内部部件和连接；不按熟悉名称补画未观察到的结构。

**method**: 原生形状、路径和内部连接组成语义组；尺寸、颜色、填充、描边来自当前原图。子件完成后再组装。

**parameters**: 当前来源的局部坐标、比例、填充、描边、接触关系；没有随包保存的用户案例参数。

**repair**: 位置偏差修当前坐标；缺件先修源清单；颜色偏差只修对应填充，再核对受影响关系。

**knowledge**: 本地知识条目只是候选方法；适用性由当前来源决定，不能继承历史通过结论。
