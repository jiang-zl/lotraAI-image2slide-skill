# EX01 侧视平面小车：部件、接触关系与知识筛选

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 原图明确为侧视简化车，可辨车身、玻璃与两只可见轮子；需要部件编辑。

**exclude**: 透视汽车照片、车的俯视图、只画一个轮子的抽象符号，不直接套该拆分。

**decomposition**: 小车 → 车身、玻璃区域、左可见轮、右可见轮；仅在源图可辨且需要时拆轮胎/轮毂。

**method**: 车身用匹配的多边形或原生路径，玻璃用适合形状，轮子优先原生圆；真实组合，保留部件 ID。

**parameters**: 车身局部坐标、两个轮心与半径、车窗轮廓、填充描边；轮心相对车身比例和接触位置由当前原图拟合。

**repair**: 轮心偏移修坐标；轮子悬空修接触或父变换；漏轮先补源清单；颜色错只修填充，再查合成。

**negative_example**: “汽车通常有四轮，所以在侧视图补画四轮”应拒绝；“车轮用圆表达”是可试的方法，但源轮形明显透视椭圆时应改表示。

**validation**: 待实际输入、原生构建、渲染与编辑验证；本例未提供实测提升。
