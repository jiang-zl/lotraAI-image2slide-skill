# EX02 服务器面板：规律与实例差异

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 原图有服务器/机柜正面及可辨面板、槽位、灯或孔。

**exclude**: 机房照片或不可辨小纹理不按固定灯数和槽位数补全。

**decomposition**: 服务器 → 外壳、各面板、可见指示灯/槽位、标签；标签独立文字。

**method**: 外壳面板用原生矩形或圆角形，灯孔用规则图元，重复结构共享参数原型。

**parameters**: 面板间距、灯大小、孔列距、圆角、描边；实例数量和差异以原图为准。

**repair**: 先修面板结构，再校准重复间距；某灯缺失时只修该实例并核对旁边标签。

**negative_example**: 把整块面板截图作为一张“可编辑 icon”；或因模板有 6 个灯就强画 6 个。

**validation**: 设计示例，尚未跑真实服务器重建或原生操作。
