# EX05 山地背景：轮廓、分层与纹理边界

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 科研示意背景的山体色块、地形轮廓与局部纹理。

**exclude**: 地质剖面数据、地图等值线或遥感影像需保留其数据含义，不能当装饰。

**decomposition**: 区域 → 主山体层、关键轮廓、规则对象、纹理与标注；有科学含义的分层独立。

**method**: 大面与山脊原生路径，规则对象独立；纹理采用受控重复图元或任务允许的局部表示。

**parameters**: 山脊地标、色块边界、填充、纹理方向和密度；关键尖峰受保护。

**repair**: 先主轮廓和层级，再纹理；局部相似提高但山脊地标偏移时拒绝晋升。

**negative_example**: 平滑消除科学上重要峰谷；只追求纹理 SSIM；把等值线看成可删装饰。

**validation**: 设计示例；真实数据背景另按 T09/T10 处理。
