# EX11 重复设备：复用原型但不复制错误

Status: `design_example`; this is not an automatic runtime quality pass.

**applies_to**: 多个设备、服务器或客户端具有相同大结构，但位置、标签或灯状态不同。

**exclude**: 视觉相似但结构不同的对象不能强行共用一个不可变模板。

**decomposition**: 原型定义共享结构；每实例保持独立语义 ID、参数和差异覆盖。

**method**: 复用已验证原生构建配方，各实例按原图参数化。

**parameters**: 共享几何参数及逐实例变换、文字、颜色和部件显隐。

**repair**: 原型错误修原型并检查所有受影响实例；实例错误只修本实例。

**negative_example**: 把标签一起复制；修 A 的填充后意外改变 B；重复对象被当成纹理丢掉独立编辑。

**validation**: 设计示例；需要实例级隔离与原型传播两个方向的验证。
