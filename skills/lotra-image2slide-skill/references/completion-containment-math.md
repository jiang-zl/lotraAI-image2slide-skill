# Persistent completion, recursive containment and real Office Math

This extends the existing `quality-loop`, source contracts, actual native checks and exact finite repair receipts. It is not another artwork acceptance core. Scope covers the complete registered original and actual slide, including imported/local-repair tasks.

## Task and execution

`task-completion TASK begin --request FILE --out FILE` freezes reconstruction, local_edit or skill_upgrade, scope and completion criteria. Reconstruction/local_edit require current whole acceptance and the official current export. Upgrades require current production, executable behavior regressions and verified publication; example artwork acceptance is a separate result.

`status`, `amend`, `branch`, `resume`, and `stop` retain identity, backlog, branch history and the next packet. A complete current audit, never caller PASS fields, checkpoints individual failed leaves. Branch outcomes bind evidence; two consecutive failed/no-gain attempts prune that strategy without closing its obligations. Explicit user additions preserve original facts and invalidate acceptance. `external_block` needs actual operation/error/evidence, exact affected obligations, adequate alternate routes, minimum recovery and equality with all remaining debt. Independent work prevents stopping.

The agent reads the entire audit and program packet, resolves prerequisites, executes a typed bounded action and checks actual gain/rollback. Source interpretation and repair planning are model duties; coordinates, set reconciliation, numerical checks, finite mutation, history and acceptance are program duties. A status question does not authorize stopping. Do not claim completion merely because a file or a report exists. Programs control official state/export; they cannot prevent arbitrary prose replies or unmanaged copies.

## Original containment contract

`containment-check TASK discover|bind|report|capture|repair` uses `recursive-containment-1` with original hash/canvas, exact original-only view, all source-unit declarations, elements, explicit potential-owner decisions, containers and original hierarchy decisions. Each container has stable ID, source bbox/evidence, direct members, separate body_parts/logical_references, effective domain and target.

Domains: native_body, native_table, native_cell, or explicit logical_polygon (optionally relative to a native coordinate owner). A group frame is a transform owner, never an inferred semantic interior. The DAG is acyclic with unique direct ownership. Every potential nested pair gets source-supported direct/ancestor/independent classification; empty tokens remain empty. Programs enforce complete source/native/merged-table-cell coverage and use iterative traversal without a semantic depth cap.

The target fixes both axes, center definition, direct_member_paint_union and source-supported placement intent. `center_content` centers a source-supported symbol, label or homogeneous content aggregate; `source_layout` preserves a module's positioned rows/subregions. Both need located original evidence before binding. Programs compile an explicit center/retain decision for every direct edge; source layout never exempts overflow, member relationships or shared-lane alignment. Tolerance is compiled before optimization from original scale plus bounded source uncertainty; a failed candidate cannot redefine it. Actual strokes, all ancestor transforms, actual host glyphs and nonrectangular interior are measured. Text-range envelopes are not painted glyph bounds. Dual-background actual-owner mattes are required for every native text/math owner. Table captures include an identical blank table control to cancel borders/styles. Exact pure translation may reuse verified owner paint; changed text, font, width/wrapping or media requires fresh capture.

Each level reports direct membership, dx/dy, tolerance, union/domain bbox, four margins, overflow and child results. Missing/unsupported/stale evidence stays unresolved. Content is inside independently of its center test. Multiline text and formulas use their full painted range, not an oversized empty text frame. Children include their body when participating in their parent; child internal content is checked independently.

Rigid inside-out repair first fixes a failed centered direct child, then its containing aggregate, preserving order, gaps and baselines. A finite independent batch rejects shared/ancestor/double-moved owners. Actual painted-center error and opposing clearance error must both pass. Repeated source text lanes freeze common left/right slot bounds, left paragraph alignment and any source-supported common typography intent; a missing raster point-size identity stays approximate. Lane repair changes only the authorized native frame/alignment/size properties, never prose or mathematical content. Overflow requires an explicit bounded body-size/layout grant; it cannot be cured by loosening a threshold. Cell content offsets reject wrapping/clipping. Every save needs actual render plus full ancestor, descendant and external relationship rechecks. Every nonempty container also gets a hash-bound source/current enlargement retaining adjacent owners and displaced content at common source coordinates. Relationship dependency never grants write permission.

## Mathematical inventory and editing

`office-math TASK discover|bind|report|repair|edit-probe` uses `office-math-contract-1`: all text/table owners and original graphic mathematical operators, exact paragraph/cell reading order, ordinary text segments and AST/source-ROI mathematical segments. All variables, numeric expressions, subscripts, superscripts, sums/products, inline spans and standalone expressions require real OMML. Ordinary letters are classified from original meaning, not regex alone.

Finite repairs replace only source-owned text bodies, retaining unrelated ZIP/native properties and native table tracks/merge ownership. Graphic mathematical strokes become one actual equation with retained nonpainting lineage. There is no plain-text, Unicode, SVG, path or image fallback. Source AST metadata is not saved-object evidence. Simple-looking and complicated math use the same representation requirement.

Content/AST/order, actual OMML representation, typography/rendering and actual edit behavior are separate checks. Isolated actual Office probes edit each existing field, save, reopen, render and independently parse the edited deck. They also compare exact ordinary-prose paragraphs and formula-zone counts. Table and mixed fields are supported; if native editing fails, the obligation remains open. Toolbar/range limitations are never called success.

Digits and punctuation in a mathematical subscript use upright mathematical style, not normal-text `m:nor`, so they share the native script scaling with adjacent variables. Equal serialized font sizes do not prove equal visual script size. Office may merge adjacent mathematical runs while saving; exact structured comparison normalizes only run boundaries, retains operators and script scopes, and rejects a changed operand, index attachment or normal-prose identifier.

## Low clarity and compatibility

`icon-clarity TASK discover|enhance|bind|report` uses the full source-unit/window/native inventory and [HD icon protocol](hd-icons.md). The host classifies clear_icon, blurred_icon, texture, photo, not_icon or unresolved against unchanged original/context. Suspect exemptions require source-context review. Enhancement is diagnostic only. Clear and blurred icons freeze actual vector-PDF 1×/2×/4× edge targets, smooth-material patches where applicable, source features and complete native-part relations; blurred icons additionally require a bounded relative clarity gain. Every actual descendant and applicable check remains mandatory. Original SSIM/PSNR remain visible diagnostics. Texture/noise is not sharpened into an invented icon.

Legacy files/history remain readable. Old native_runs cannot pass new math requirements; old missing hierarchy decisions cannot pass current closure. Historical finite transactions replay only their registered immutable original contract, while current acceptance must use the new complete contract. Exact unchanged owner mattes may be transported across pure translation; altered paint, fonts, table or media needs fresh actual capture. Mask cache keys include verified bytes and preserve complete occupied sample geometry.

## Reports and delivery

Report object coverage, declared relation coverage, required measurement coverage and current hard-pass coverage with separate denominators. Each row includes stable ID/binding, importance, target/basis, actual value, frozen tolerance/unit, status, evidence and next action. PASS/FAIL, required_unmeasured, UNSUPPORTED, STALE and source-supported not-applicable remain distinct. Counts are coverage evidence, never beauty scores. No global average compensates a critical local failure.

The user report gives targets and outcomes in plain language; complete trees, mathematical maps, actual editor/connector evidence, property/region protection and remaining packets are machine-readable. A published test PPT is explicitly a case result; only the current `quality-loop export` receipt accepts a whole reconstruction. Upgrade verification reruns bundled assertions, verifies actual current case targets/protection/render and all published bytes. It cannot accept an unfinished example by declaring the upgrade complete.

Actual Office: Windows PowerPoint with isolated task copies. Actual edit evidence binds the current plan, probe implementation, unchanged staged input, edited saved bytes, ordinary prose and both rendered states. If the direct PNG exporter fails but the same actual PowerPoint job saved its PDF, reuse the existing fixed-canvas PDF rasterizer and independently replay every preview pixel. Preserve failed or partial PNGs, original errors and the explicit PowerPoint-PDF route; it is not a direct PNG-export success. Neither route's failure can become editing PASS. Unsupported hosts must keep actual editing behavior unverified. CPU-only/offline OCR resources remain the inherited verified companion runtime; this upgrade does not require a new model API or GPU.

An independently verified prior actual PowerPoint render may supply the before-state only when it binds the exact unchanged input PPT bytes. Preserve its PDF, PNG, render receipt, host session and job receipt in the immutable probe plan and verify them again. Report this as cached actual before-render evidence, never a new export. The edited after-state must still be saved, reopened and rendered by the current actual job. A different PPT, partial cache, alternative renderer, changed source or failed after-render cannot use this route to pass.

If both direct PNG and PDF fail, the owned current PowerPoint document may export its native EMF. Preserve the direct failures, bind EMF and derived preview hashes to the real current job, and independently decode the same EMF through the declared fixed-canvas Windows GDI kernel. Report `PowerPoint_native_EMF_Windows_GDI`; it is actual native host rendering, but is neither a successful direct PNG export nor a PDF export. Missing native EMF, failed pixel replay or a host without this codec keeps editing behavior unverified.

If all three full-slide exports fail after saved text/math edits, PowerPoint may independently export each actually edited owner as native EMF. This bounded route accepts only text/math operations and requires exact coverage of every operation index, including repeated formula spans in one owner and the prose edit. Verify each metafile and nonblank preview against the real current job and independently replay its pixels. Report this as owner-only actual editor rendering; preserve all full-slide failures and never call it a full after-slide render. Connector, path, group or geometric edits cannot use this route. The unmodified reconstructed artwork still needs its separate complete actual render and whole-quality gate.

Before-render transport compresses independently verified original artifact bytes without changing their hashes; the declared 128 MiB decoded resource limit is checked before launching Office and again during bounded decompression. A cache resource failure cannot become editing PASS. Whole audits preserve a previously satisfied frame-rule regression as a measured failure and continue other checks; mutation/adoption guards still reject that regression.
