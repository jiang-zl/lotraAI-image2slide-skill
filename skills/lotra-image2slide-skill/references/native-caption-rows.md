# Original native caption rows

Use `native-text-lines TASK REQUEST --out PROPOSAL` only for an independently read two-to-six-line plain native caption with its exact original literal and glyph mask. The one original text owner, family, paragraph count, native frame and other content remain unchanged. Mixed mathematical runs and colored captions use their existing routes.

Request: current `baseline_hash`, original `source_hash`, `unit`, `source_evidence`, and optionally independently observed dark achromatic `source_ink_rgb`. The program reads the saved Office-owned complete caption and original independent mask, measures each row, fits shared font size/advance, line pitch and anchored pose in saved deck point units, and returns a small hashed local proposal. It creates no new render and changes no quality status. Reuse the proposal with the regular native writer; do not repeat a gallery/global source analysis.

Original black glyphs must be separate from neighboring blue artwork, server edges and separators. Retain old definitions/targets when correcting that ownership; the correction is not a drawing gain. After a scoped actual drawing, compare exact literal, each original row, font weight/pose and affected source relationships. No whole-block score, proposal residual or blacker ink establishes satisfaction. Keep unmatched properties open and preserve already satisfactory native geometry elsewhere.

When fixed source rows cannot share the current font proportions, do not force wide tracking. Supply `current_font:{path,sha256}` plus one `source_rows` record per original line: `source_style:{font,bold,italic}`, `source_font:{path,sha256}` and `source_typography_evidence`. The conditional program preserves one native text owner/exact paragraph literals and writes original row-specific runs. Private installed source outlines estimate size/advance and font leading; actual Office still decides font/shape/weight/spacing quality. Different-family multi-row layouts and math remain outside this bounded route. A rejected proposal keeps `row-plan.json` with the exact row/advance/pitch reason; resume that evidence rather than repeating the source observation.

Rows can have different original anchors despite belonging to one caption. The proposal returns bounded `paragraph_layout` left/right native indents in points. The existing native builder writes actual paragraph margins inside the same text frame. This preserves separate source row centers and editable row-specific styles without splitting/flattering the caption or independently registering output windows. All original per-row and neighbor metrics remain unchanged; source font/row layout estimates are not acceptance.


Original width must be supported by its own glyph ink: faint/chromatic components that alone extend a black row beyond solid glyph support raise an ownership diagnosis before font fitting. Never delete punctuation by component size. Read and correct the independently evidenced foreign source fragments through the existing source-correction route, retaining history and targets.

A saved actual_response descriptor may reuse a nonselected caption response for local pose/pitch/advance fitting without adopting its failed page. Bind the selected baseline, original source, saved scene/PPT/render/preview hashes, native owner/frame/literal/canvas. Same source-style rows calibrate actual glyph size and private outline widths; corrected rows retain native paragraphs. The protected action still applies only the named owner to the selected page and requires actual own-part and affected-neighbor assessment.

A source-matched regular native row response with already satisfied original ink mass and source-height tolerance keeps its font size; refine pose/pitch/advance separately. Changing a row family/weight still uses original outline estimates until an actual matching source-style row exists. Original colored subpixel edges belong to glyph ink; an achromatic selector alone must not erase them. Source-domain revisions retain previous masks and fixed targets and do not count as drawing gains.
