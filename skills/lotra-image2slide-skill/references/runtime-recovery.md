# Runtime recovery without replaying history

Keep the unchanged original, persisted state and registered artifact hashes.
Resume the current task with context-control; it verifies these dependencies
and keeps every pending obligation. Never reconstruct state from conversation
or use an old PASS after source/code/context changes.

Discover actual files with targeted searches before opening an assumed path.
Use the registered project runtime and native-library descriptor; a global
interpreter missing packages is not the prepared runtime. Relative resource
spellings are validated before host Path conversion. See path-portability.md.

Keep a pending Scene on prebuild failure; if native saving succeeded and only
render failed, retry that saved candidate. Inspect the owned dispatch logs and
exit status before concluding that a blank transport output is a drawing
result. On Windows, process helpers use hidden windows and exact task-local
logs. WSL bulk source/release copying uses the configured WSL-side route.

Use the configured isolated Office bridge. Do not repeatedly open global COM,
change global modules/fonts or close shared Office/user documents. Keep the
recorded source/host/font limits and select an evidenced recovery branch.
One ineffective branch does not terminate actionable pending work.

Unknown native geometry or dependency discovery requires complete checking,
with its exact error retained. Cache eviction affects only recomputable facts;
it must preserve source contracts, observations, historical bests, font
resources and replay evidence. See context-storage.md for current scopes.
