# Per-textbox and mathematical-span quality

Read only for original text observation, text/math repair or delivery. Use the
single core and source coordinates. No whole-image average can satisfy a word,
table cell, equation, subscript or accent.

## Source evidence before drawing

1. Inventory actual native owners with textbox-quality discover. Read each
   original-only crop, in packets of at most eight. Re-read ambiguous words
   independently with the saved/prior answer hidden. Store both readings,
   exact crop identities, visible lines and original glyph ownership.
2. Disagreement means a source-reading defect. Preserve the earlier reading;
   correct the guide with original evidence. Never compare saved PPT words
   only against the same transcription that produced them.
3. Bind exact native plain text and each inline OMML AST separately. Do not
   NFKC-fold symbols or remove all spaces. Original source pixels do not
   establish font names, point sizes or bold flags: record unknown metadata
   and observable glyph/stroke geometry. Raster blur is uncertainty, not a
   mandate to blur the new output.
4. Declare original word domains excluding arrows, frames, watermark and
   other layers. Declare separate math zones for observed scripts, accents,
   operators, delimiter pairs and mixed-text baselines. Unknown evidence
   stays unresolved. A whole formula mask cannot certify a tiny index.

## Metrics and localized cause

The actual PowerPoint render, saved PPTX hash, font inventory, owner ink bounds,
source crops, frozen targets and method form a cache key. Fixed source-canvas
foreground F1, one-pixel edge F1, 95th percentile edge distance and ink extents
measure actual placement. Shape-normalized F1 is supplementary and cannot
compensate absolute size or placement. Ink density agreement is a stroke-weight
proxy, not proof of original bold metadata. Width/height ratios measure size.
Line count, ink-row anchors and line pitch measure line layout; a pixel ink
anchor is not an exact recovered typographic baseline.
Multiline ink pitch has an independent1.5px target and fixed.75px retention
allowance. Only measured prose-row pitch is asserted; mathematical script
islands are separate roles. For ambiguous character/word spacing, bind visible
word or glyph zones and compare them independently, then use native per-run
advance adjustments. Normalized shape/presence cannot waive a bad local zone.
Native format_match=1 without native_expected means no metadata assertion,
not proof that a raster's bold/font/alignment metadata was recovered.
An empty original role is an unresolved source-domain problem. With real
rendered evidence, an empty actual expected-role window is observed_absence
(local presence/shape/size scores0; location unknown), not missing render data
and not proof that the native AST disappeared. Delivery cannot waive that
role; locate its actual glyph and repair the supported root cause.

Exact literal, every mathematical AST and explicitly observed native formatting
are gates at 1.0. Default stretch minima: F1 .90, edge F1 .95, shape F1 .90,
weight .92, size .96; position/line-ink anchor errors <=1.5 original pixels.
Per-source bounds may be declared before drawing, never loosened to rescue a
candidate. Report individual residuals and measured uncertainty. SSIM/PSNR are
auxiliary and cannot cancel a content, style, size or script defect.
The binder rejects goals weaker than the mandatory defaults and fabricated
raster font-name/point-size/bold metadata. Original image/crop/mask hashes,
actual owner bounds, host receipt and font inventory are checked before cache
reuse; a cached score cannot waive changed or missing evidence.

- Wrong letter/index: original interpretation or native serialization.
- Good normalized shape but bad fixed F1: pose/size/spacing.
- Bad normalized shape: family, italic/style or glyph construction.
- Good shape but low density agreement: stroke weight or sampling.
- Correct first row but shifted subsequent rows: paragraph pitch/baseline.
- Neighbor collision: use relative-layout relationships, painted ink and
  the actual container body; do not solve it by shrinking correct glyphs.

## Action and retention

Cache a bounded native font atlas on the same actual host; screen plausible
families/weights once, then fit only the located owner. Reuse font_fit,
text_pose_fit, native_text_lines and source_math. PDF family/ToUnicode aliases
alone are not font-use proof. Use available, legally acquired fonts on the
rendering host; do not bundle private fonts into public releases.

The native commit rejects source-inconsistent text/math before adoption.
Actual retention evaluates affected owners and independent math zones, protects
satisfactory properties and keeps below-target residuals explicit. Slight
sampling tolerances are fixed in the program; content, structure and native
format have no tolerance. The existing native diff/masked local-edit machinery
protects other objects and ungranted fields. Local edits never regenerate the
whole page. Preserve group movement dependencies and selected source spacing.

After two attempts without meaningful gains for the same cause, prune that
branch and retain the better result. Missing glyph ownership, wrong scientific
content or unobserved important math roles cannot be called satisfactory.
Convergence is exact content, no obvious type/size/layout defect at use size,
protected approved artwork, and disclosed minor raster/font residuals, not a
claim that unknown raster font metadata was recovered.

Paper PDF export requests MuPDF's native used-glyph font subsetting immediately
before compact saving; if large Office CFF font data remains unchanged, use
the separately declared fontTools parser once as a bounded fallback. Record
actual before/after embedded-font bytes; unsupported data may remain large.
Do not replace
the CJK family or flatten the native PPT to force smaller files. Original
Office/PPT observations remain evidence; serialization is not a drawing gain.
PDF-to-SVG grayscale luminosity masks are canonicalized as equivalent white
RGBA alpha, preserving geometry and ordinary images. Otherwise alpha-only
SVG consumers can render a glyph rectangle as a black block. Compact paper
proposals must preserve each actual word region; smaller bytes cannot waive
glyph/weight/size/location regression. Original font metadata remains unknown.

Commands: textbox-quality TASK discover|bind|report --out FILE; bind also needs
--request FILE. New tasks default to source_textbox_quality=true. Original-only
packets are routed by next/submit, saved drawing and actual retention gates
are automatic. Legacy tasks bind only changed text/math owners and retain prior
non-target artwork; auditing old tasks does not silently upgrade their results.
New-task configuration cannot disable this source_textbox_quality requirement.
An actually absent/misplaced role can be repaired: when its new location first
becomes measurable, record newly_measured rather than inventing an earlier
numeric score or rejecting progress solely because the earlier location was
unknown. A required new measure still missing cannot be adopted.

Use atlas --request with baseline_hash,1..8 confirmed ids and1..4 plain native
font/style variants. Its source/owner/host/font-inventory cache reuses saved
native text bodies and group transforms. Screen once; the complete slide is
still the actual retention authority. Relative glyph centers cannot fit a
left-aligned textbox: use its actual left ink bearing after size/advance fit.
For math, use source-declared/native paragraph count, independent script/accent
zones and line anchors; disconnected superscripts cannot be counted as extra
prose lines. Satisfaction intervals remain fixed: a sampling variation inside
an already-met interval is preservation, not a reason for endless retries.
