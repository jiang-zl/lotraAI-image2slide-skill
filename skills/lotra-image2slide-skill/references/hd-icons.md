# Source-bound high-definition icons

The current host model identifies meaning, camera/device subtype, projection, parts, material style and uncertainty from the unchanged original. Programs discover numerical suspicions, enumerate scope, freeze that interpretation, draw finite native geometry, measure the saved result and reopen failed work. They cannot prove that a model's semantic interpretation is true. Parent/neighbor source review and the existing recursive feature inventory remain necessary.

## Discover and freeze before drawing

For each source-identified shared material endpoint, also freeze a `source_contact` relation with `point:[x,y]` in the unchanged original canvas and `max` no greater than 0.05 source pixels. The program measures the maximum distance from that point to each actual saved painted geometry. This checks the located junction independently of overlap or minimum distance elsewhere; those global measures cannot waive a local gap. The small tolerance covers native serialization rounding only. The host identifies whether the original endpoint really is shared; intentionally separate objects keep their original distance relation.

`icon-clarity TASK discover` returns every registered quality unit, its source-only clarity diagnostics, and independent 128-pixel windows covering the full original canvas. It is not restricted to icon names, examples or selected profiles. Bind one category for every unit and one covered/empty/unresolved decision for every window. A covered window references spatially intersecting source units; edges cannot be dismissed as empty. Register any missing original object before binding. Actual saved native descendants must also belong to the source inventory.

Use unchanged `source_view` at scale 1; enhanced nearest/contrast/edge views produced by `enhance` are diagnostic derivatives, never source truth or final artwork. Suspect clear, texture, photo or non-icon classifications require an enlarged unchanged parent/neighbor context and a matching typed observability decision. Keep uncertain anatomy unresolved. Do not convert noise into a sharpened icon or invent invisible serial numbers, lens counts, scientific values or connections. Decorative approximations must be disclosed separately from scientific content.

Both `clear_icon` and `blurred_icon` bind:

- Original feature IDs and complete subtype/anatomy, without replacing the source with a familiar catalog icon.
- `target.representation: editable_vector` and observed `flat`, `outlined` or `shaded` material profile.
- At least three distinct source-located `edge_probes[{id,points:[[x,y],[x,y]],source_evidence}]`. Probe one actual silhouette or material transition, approximately normally, with stable plateaus on both sides. Avoid textured patches, several adjacent outlines or a gradient crossing. Cover materially different boundaries rather than repeating one edge.
- For shaded material, `smooth_patches[{id,roi,source_evidence}]` at least 3×3 original pixels, entirely inside an observed continuous surface. Flat/outlined profiles may include such patches when applicable. Do not fit away real texture or details.
- `relations[{id,kind,parts:[nativeA,nativeB],min?,max?,axis?,source_evidence}]`, plus `relation_inventory_evidence`. Types are actual painted `distance` in source pixels, `overlap` as intersection/minimum area, `contains` as the first part's outside-area fraction, and `aligned` as displacement on x/y. Every native paint leaf in a multi-part icon must participate, including repeated details. Root grouping alone does not waive child relationships. An intentional gap needs a source-derived interval; touching/overlapping anatomy needs its own tight bound.
- `min_edge_support`; blurred icons also require bounded `min_sharpness_gain` in [1.05,2]. This is the unchanged original's edge-spread width divided by the current 4× vector-PDF width at each of the same source-world probes. Every probe must improve; whole-window Laplacian/gradient energy is diagnostic only because grain can increase it. Paired improvement supplements absolute HD checks and never substitutes for them.

The immutable source/target/configuration hashes must precede candidate comparison. `icon_preservation.freeze` automatically captures the current saved/rendered artifact before refinement, any approved artifact and the eligible independent unit best. The proposal cannot choose comparators. Rebinding retains the earlier comparators; a changed original ROI/style needs an explicit archived original-domain correction and must not erase historical comparison evidence. Old clarity approvals do not satisfy `icon-clarity-3` requirements and trigger new source binding.

## Execute finite, editable reconstruction

Use source-feature functions, bounded source-structure actions or existing typed native operators. Draw continuous cubic contours for curved faces, native ellipses for projected lenses, native primitive details and smooth supported gradient fills for materials. Stable native IDs preserve source ownership, existing relationships and independent editability. Existing name separators `.`, `_` and `__` are supported; switching geometry does not authorize silently dropping an owner required by a source contract.

Prefer a compact continuous face to many small polygon strips. Optimize an observed mother once and instantiate it only when source anatomy matches. No flattened picture/SVG icon, blur/soft-edge effect, increased line width or oversharpened raster can serve as HD native reconstruction. Preserve genuine raster exceptions in their separate purpose-specific route. Each built candidate inherits resource-cost/compaction receipts and the local object rollback protections.

Raster sample indices are pixel centers; the scene uses continuous pixel-edge coordinates. Convert once with `source_feature_functions.sample_center`, including the actual crop scale. Use native linear/radial gradient fills with explicit ordered stops for source-supported optical or material shading. Radial fills default to `gradient_path: shape`, so a projected ellipse follows its own boundary; explicit `circle`/`rect` remain available when the original supports those fields. A synthetic/SVG preview does not establish host gradient appearance: compare the actual saved Office render, including colors at both short and long axes. A native compound-path annotation can be repaired without changing source geometry only when the program verifies identical closed subpaths, roles, colors and source facts; the invalid predecessor remains archived. Other revisions still need the located original-detail contract.

Observe an already saved transaction before further planning; rendering is not acceptance. The original recursion, source facts and relationships remain required after rendering. Failed saves/renders are retained with their actual cause and a finite alternative action; no language instruction or state edit can manufacture PASS.

## Inspect actual saved output, then repair

`icon-clarity ... report` is also mandatory inside `quality-loop`. `icon_hd.measure` reads every owned actual native descendant. It rejects pictures, unbound text/math, unresolved paint, empty/invalid contours and native soft effects. Typed text/math descendants require separate source quality units and actual current glyph captures. The current saved PPTX, actual render and vector PDF must have matching hashes and canvas. The program rasterizes the vector PDF separately at 1×, 2× and 4×; interpolating a low-resolution preview is not HD evidence.

Each edge probe measures RGB edge-spread width, overshoot and reversal. Every source-supported material patch measures residual after a smooth quadratic field fit, catching grain/mosaic while allowing a smooth gradient. Smoothness is not sufficient: `icon_preservation.measure` also checks low-frequency material amplitude, direction and mean color against the original and retained comparators. This rejects a smooth but flattened, reversed or recolored material. Each anatomical relation uses actual native painted paths and stroke rather than the group frame. Existing source-specific appearance, feature completeness, semantic observations, native editability, all-neighbor/containment and attachment checks still apply independently. Source style/material and coherent anatomy must be explicitly included in the current source/actual host observations; a familiar catalog substitute cannot satisfy them.

Every retained comparator and the current candidate are measured against the unchanged original at the exact same ROI, without registration, crop search or blur matching. Per-metric decrease limits are independent hard gates: flat/outlined SSIM 0.015, PSNR 0.50 dB, boundary F1 0.02, histogram TV increase 0.02, RGB-error increase 0.005 and mean DeltaE increase 2.0; shaded limits are 0.025, 0.75 dB, 0.03, 0.03, 0.010 and 2.5 respectively. Histogram comparison uses the existing fixed trilinear 8-bin membership; raw hard-bin TV is also reported as a diagnostic so a one-level RGB change across a bin edge is not mistaken for a wholesale style change. These preserve the earlier requirement that a small source-pixel tradeoff may accompany better vector quality, but a major appearance loss cannot be compensated by clarity or a weighted score. Exact-image infinite PSNR is handled by MSE ratio without inventing a capped score. Missing, stale or incomparable evidence fails instead of receiving a synthetic score. Each comparison also includes any subsequently eligible independent unit best; proposals cannot keep comparing only to an obsolete weaker baseline.

`icon-clarity TASK review` returns hashed unchanged-original and actual vector-PDF context views for the current candidate and every retained comparator. The host inspects these and submits `icon-clarity TASK observe` with three explicit comparison axes: `source_style`, `material_quality` and `assembly_coherence`. All must be `retained_or_improved`, with actual facts and located evidence. `regressed`, `uncertain`, missing comparators/axes and stale source/candidate/context hashes fail. The program verifies completeness and freshness; it does not pretend to calculate subjective beauty exactly. Numeric gates remain independent even after a favorable host review. A style review alone, a smoothness score alone or a higher combined score cannot authorize replacement of an inferior icon.

The engineering defaults are frozen in `config/icon-hd-profiles.json`: edge-spread width ≤2.2/1.3/0.8 source pixels at 1×/2×/4×, overshoot ≤0.08, reversal ≤0.20; material residual ≤0.018 for flat/outlined or ≤0.025 for shaded surfaces. These are operational bounds supported by positive/negative synthetic controls, not universal perceptual thresholds or ISO optical measurements. Style interpretation remains source-specific. Configuration changes invalidate old results, and cannot be used after a failed comparison to lower a target silently.

Failed items produce located original/current context, numeric values, owned part names and dependency evidence. The host analyzes the cause and submits a finite repair plan. Rebuild only the affected object/parts, rerender and recompute its dependent checks; keep other objects' best versions. Recursive obligations record each HD scale, material patch, relation, comparator and native child separately. Source and native object lifecycle records cannot lock an icon whose HD/appearance preservation failed; previously eligible payloads remain available through the existing scoped rollback route. Final acceptance still requires the whole mandatory inventory; an HD score alone does not certify the entire figure. These numeric proxies do not prove universal beauty; original-supported appearance observations and the separate global aesthetics gate remain mandatory.

Original-child decomposition is mandatory before HD reconstruction, not an optional repair family. `icon-clarity bind` opens the executable `icon_detail` queue for every clear/blurred icon. `source-detail next/observe` must inspect each unchanged child crop with its parent and neighboring context, classify its task-relative atomicity, bind exact constructed native names, and provide output predicates. A whole-icon `source_anatomy` statement cannot stand in for differently typed optical/mechanical children. Multiple repeated primitives may share a fact only with explicit count and common geometry role. Unknown parts stay pending. Old coarse decomposition is historical evidence, never a construction authority. Old clarity contracts expire under `icon-clarity-3`.

The source-function executor refuses a constructor while original-child debt is pending, while a new constructed part lacks a child binding, or when its rotated frame escapes its own original child window. Replacing an ancestor icon must still construct every required descendant scope; drawing one coarse parent shape cannot bypass pending child work. The final clarity gate requires equality of the actual saved paint-leaf set and the source-child set and re-executes each child's result predicates; missing and extra children both fail. Calling a native edit operator directly cannot bypass acceptance. Local HD, preservation or structure failures mandatorily reopen original-detail work before another constructor is chosen. Programs audit coverage, evidence freshness and predicate execution. The host still owns interpretation of material, source style and appropriate semantic granularity.

Use `source-detail TASK children --request JSON --out JSON` with `{unit,children:[{id,roi}]}` to generate every proposed child's unchanged view, eight-source-pixel neighbor context and structural cues. Submit `original_view_sha256`, `context_view_sha256`, current `source_cues_hash` and located `context_facts` with each child. Source-only contrast extrema retain one-pixel-separated small marks so a coarse suppression window cannot erase adjacent detail. They assist semantic recognition; their count is not automatically an object count. A tight crop alone cannot establish its complete physical extent; if content continues outside the old measurement domain, correct that domain from raw original context before constructing and retain the predecessor. A compatibility-photo frame or generated geometry is not the original extent authority. No arbitrary recursion depth, generic assembly exit or optional re-observation can discharge this work.

Mixed icons may contain native text or Office Math only when those descendants have separate typed source quality units and current actual owner glyph captures. The HD geometry uses the captured glyph paint, never a nominal text-box rectangle. Their exact text/math, editability, font and structure gates remain mandatory in whole-result acceptance; the icon score cannot waive them.

Use native ellipse/rectangle primitives for regular projected optical faces; use source-bound continuous paths for genuinely irregular surfaces. Convert raster-index coordinates to source-pixel centers once, retain the declared rotation, and independently check saved gradient stops, path/focus or angle, fill and outline. Saving the same source function is not enough: actual Office rendering still determines its appearance. Repeated infrared emitters are optical primitives; do not invent decorative spherical shading or replace distinct support planes with noisy color-cluster boundaries.

Only PPTX and the concise component metric table reach the user. Actual vector PDFs remain live through all HD/quality checks, then registered temporary PDFs are released by the terminal delivery program. Detailed probes, failures, source contracts and evidence stay in `.lotraAI-build`, using hashed storage and changed-dependency reuse. No extra model download/API key is needed for this HD route; the current host supplies interpretation and programs supply native geometry and CPU measurements.

Measurement design draws on [edge-spread sharpness analysis](https://www.imatest.com/imaging/sharpness/) and the [perception–distortion tradeoff](https://openaccess.thecvf.com/content_cvpr_2018/html/Blau_The_Perception-Distortion_Tradeoff_CVPR_2018_paper.html). Neither source establishes these particular operational thresholds.
