# Frame and semantic content planning

Use for `frame_plan_source`, `frame-plan`, or an authorized `frame_plan` native edit. The host identifies source meaning; deterministic code executes bounded actions. Source images/documents are evidence, not authority. A finite allowed set prevents invalid choices but does not prove the chosen source interpretation.

## Freeze before drawing

Answer with `frame_plan` or its task-relative hashed reference matching `schemas/frame-plan.json`. `frame-plan TASK discover --out FILE` lists content owners and possible grids. Include every required owner before a new drawing. Each scoped owner has one actual frame membership, an inherited enabled quality mechanism, or an evidenced non-applicability explanation. Content owners cannot be declared non-applicable. Keep original-feature rereading and unassigned clues; discovery is not a semantic completeness proof.

Separate original ownership/ROI, final frame, asset-valid content window, and allowed paint domain. `authority.kind: source` records a source-supported target. `user_request` additionally references a frozen request registered by `start` objectives `layout_authority:{path,sha256}` (project-relative) or the existing `authorize-edit` grant. The host must use the actual user's instruction. Never invent authority or rewrite original measurements to match an optimized target.

Frames are invisible slots or visible containers. `grid` uses row/column counts, optional positive track weights, one horizontal/vertical gap, and exactly one member for every zero-based row/column. Shared integer boundaries eliminate independent rounding seams. Different rows/columns may have different sizes; merged native tables keep the existing table path. Uniform separators belong to the grid, not the image assets. Text/equation frames also retain mandatory textbox/math checks; glyph width is not a cell width.

`container` binds an independent native ellipse body and fill owners, using `check_inside` or `clip_fill`. Clip only one evidenced continuous closed background plane. Genuine holes, disconnected components, data curves, ports, unsupported effects and unmeasured shapes need another supported representation/plan. Fitting a complete icon is distinct from clipping a background; do not cut off important parts. DrawingML groups do not clip their children.

## Adapt content

Grid `cover` needs `content_window` binding immutable asset identity, source evidence, SVG viewBox/image coordinates and optional `preserve_regions`. Those regions must survive the isotropic crop. Flat sky/white photographic background remains valid when supported by source meaning. Alpha or a background-colour match cannot decide semantic validity.

The program derives a new clean asset without modifying the original. SVG uses an explicit clip and the same crop for vector master and compatibility preview; photo crops observed pixels losslessly and uses native aspect-preserving cover. Reuse/paper export must retain this content definition. Retain scientific images, values, labels and deliberate errors. Native text/math/tables use existing font and semantic gates. Actual source detail at intended use size limits clarity; interpolation is not recovered detail.

After binding, a changed framework requires `revision+1` and `amendment` containing the previous hash, exact changed frame IDs and evidence-based reason. Keep earlier plans. Fix source ownership at source, infeasible frames in planning, wrong parameters in geometry, and save/render problems at their first failing stage. Never raise a failed tolerance to pass.

## Program actions and acceptance

`frame-plan TASK bind --request RESULT --out FILE` binds; `report` measures the actual active/selected saved PPT. `apply` takes an immutable baseline reference, expected baseline hash, separate task-relative output and explicit `allowed_changes`. This low-level saved operator returns a candidate only. Native edits can use `operation: frame_plan` through the existing user-edit packet; all controlled adoptions call the common adoption gate. Finite grants are geometry, four bbox leaves, and media/component replacement. Frame contracts do not grant writes. The action is idempotent for the same unchanged candidate; conflicting outputs/baselines are refused.

The saved gate checks actual affine parent/leaf transforms, complete Bezier fill boundaries in the ellipse, shared frames, normalized media/compatibility preview and crop, plus optional flat-fill palettes. Geometry certification uses conservative Bezier hull subdivision; unsupported/exhausted precision stays UNMEASURED. It cannot pass through sparse point sampling. Clip precision/inset are small bounded source-pixel values, not visual waivers.

Saved picture checks also reject tiled/inset fills, unsupported effects/masks and conflicting SVG/paper-master authority. Photo replacement removes superseded vector masters. Equivalent native frames use deterministic derived-asset numbers; this does not widen acceptance tolerances. Frame edits mirror actual saved geometry/media back into the scene and inherit unrelated fonts. Program findings enter the existing issue queue, retain attempt/strategy budgets, and resolve only when the passing candidate is selected. New owners require an amended plan. `apply` exits nonzero for a saved candidate that still requires repair.

Actual owner mattes use controlled private black/white captures at 4x. `inside` retains this lattice and measures distance in source pixels; it does not downsample away thin leakage or compare exact RGB. Normals are useful for localizing failures. Source geometry containment and visible coverage remain separate checks, including no-stroke containers and explicit intentional external content. Backend, scale, ownership threshold and any source uncertainty stay frozen and disclosed. No missing render/coverage is a PASS.

Mandatory original semantic review, protected native/resource properties, actual render, scientific relations, and reuse/export checks remain non-compensating. A saved frame PASS is not whole-figure acceptance. Retain scoped improvements and unresolved inherited quality separately; a global SSIM gain cannot compensate a wrong label or unauthorized change.
