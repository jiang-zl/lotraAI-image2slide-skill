# Saved native font geometry for paper output

Use this conditional route when the selected editable PowerPoint word is satisfactory, but the actual PDF/SVG has a different serif, weight, tracking or position. Requested font names do not establish glyph fidelity. The exact existing native PPT stays unchanged.

1. Reuse saved actual native glyph/advance receipts. If absent, discover an available Office host, including Windows from WSL. `scripts/windows_native_word_export.ps1` stages an owned read-only copy and exports only manifest-bound named native words as EMF5/HD PNG and actual character advances. No shared Office restart, user-document edits, or global font/skill changes. Shape.Export scaling is relative to the slide; use actual slide dimensions. Keep opaque fonts/licenses out of public packages.
2. Preserve the original PPT/scene hashes and current word/parent-frame equality. Native glyphs use actual global device-to-point coordinates. A font-dependent EMF text record is not already a portable outline. A declared <=13EMU paper-only same-colour title hairline can ask Office for actual glyph paths; the program verifies that no other native package data changes. Unsupported drawing records and source raster transfers stay unresolved.
3. Cache the actual EMF/receipt once under the task. Call `native-word-paper task request.json --out report.json`. The request contains `baseline_hash`, `base_native_hash`, hash-bound `base_pdf` and fixed-original-grid `base_preview`, a fresh task-relative `output`, and1..8 `words`. Each word has `unit`, `native_baseline` (pptx/scene artifact entries), `emf`, `receipt`; a path-capture carrier additionally has `captured_pptx` and `capture_outline_emu`. Artifact entries contain task-relative `path` and exact `sha256`.
4. The program uses existing source-unit masks/ROIs/metrics, fits one bounded output-stroke parameter to original word mass using cached glyph geometry, and measures each actual complete paper word independently. Native partial text-outline contours may replace their recorded DIB stipple with the original explicit opacity; this is a measured vector reconstruction, not lossless EMF playback. The selected editable native text/font/pose/geometry remains protected.
5. Only the exact old PDF characters are removed; non-text graphics/images stay. A white rectangle is unsuitable when a bad word overlaps an independent icon. Keep the actual old/new word edit domain separate from the fixed original quality ROI, so removing an old misplaced glyph is authorized without padding its score. Record0outside-owner pixel changes. Return affected source-defined word/icon gaps independently; an appearance score cannot close a spacing debt.
6. Inspect actual enlarged words/context and affected relations. Numeric minima do not prove the original serif, glyph details or spacing. Keep failures/proposals, semantic issues and missing relations explicit; do not accept the complete paper/page from this local result. Generate SVG from the final saved PDF and evaluate applicable output artifacts before final selection.

This avoids repeated model-generated glyph paths, global font swaps and repeated whole-page reconstruction. The original/native source evidence and actual response are reusable storage; no task-specific filenames, letters, icon names, or source coordinates are embedded in the program.
