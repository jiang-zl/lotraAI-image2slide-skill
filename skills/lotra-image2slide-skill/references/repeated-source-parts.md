# Repeated original parts and one shared mother

Repeated objects can differ in position, pose, size and content. The original
repeat survey is mandatory in ordinary construction and whole-quality export.
It is independent of the current drawing and cannot use a low-quality candidate
to train its decisions. Run `source-repeat TASK scan|next|observe|report`.

The program screens registered original units at several levels, compares
normalised original edge/colour samples under quarter turns and emits a bounded
spanning forest of pairs. Thresholds are engineering screening defaults, not a
semantic equality test. Overlapping views of the same object are not repetitions.
The detector may miss an arbitrary pose, occlusion or changing interior. The
host also nominates source-supported repetitions when inspecting the original;
source completeness never depends solely on this numerical detector.

The host confirms `shared_geometry`, `shared_with_variants` or `distinct` from
both original crops. Shape reuse must not copy a different label, formula,
connector port, signal meaning or missing detail. Variant decisions must name
the independent varying roles. Common native constructors are program-verified;
the survey cannot close solely with a prose statement that things look similar.

Optimise one well-resolved mother using its class-specific local loop. Freeze
its independent original function only after actual rendering, native geometry
and local hard checks pass. `source_repeat.freeze_mother` stores its immutable
geometry and source locator. `clone_function` numerically instantiates that
mother in an independently located original unit, checks owner scope, transforms
all supported contours/holes/parts, and scales stroke width consistently. Its
mother hash, source instance ROI, pose and owner remain in `repeat_instance`.
For a tight dark contour, the implemented `dark_centroid` anchor measures
unchanged original ink rather than treating the crop centre as the part centre.
Its support and bounded correction are checked; candidate pixels never supply
the anchor. Positioning still requires each instance's native and local checks.
`source-feature bind` rejects a clone changed outside this transformation.
`source-structure restore` executes the ordinary guarded native transaction.

Use the existing `natural_icon`/native template and shared mother mechanisms for
geometry requiring their curve/pose constructors. The source-function clone
operator has finite supported primitive classes; an unsupported oriented
ellipse or anisotropic arc requires its analytic model, not silent deformation.
Raw photos, textual content and formulas keep their own specialised routes.

For a document icon, the paper body, folded corner, inside motif, rules and pen
can be separate reusable mothers or one source-supported semantic family. Keep
the editable children and original content correspondence. A logical layer does
not require one giant group. A family changes only its declared common geometry;
varying content stays independent.

An independently frozen original feature function can correct an older source
palette fact. The program recompiles only that source-owned palette entry to
the exact original-function colour, preserves the predecessor and function
hash, and keeps every geometric tolerance and user-owned palette unchanged.
It cannot adopt a candidate colour or widen a failed colour range.

Each instance still needs its own original ROI/parts, native ID mapping,
transform/pose, source metrics, layer/attachment predicates and local history.
When the mother changes, related instance observations become stale via native
dependencies; reinstantiate and recheck the affected family, not the whole page.
If one instance regresses, its ordinary object loop selects/rolls back that
instance while retaining the mother, variant reason and failed attempt. Budget
exhaustion or similarity alone cannot lock an unchecked instance.

Reuse reduces repeated semantic analysis and geometry generation, not coverage.
The program can guarantee immutable construction, bounded scope, retained
mapping and checks for every registered instance. The host remains responsible
for correct original anatomy and semantic family classification; unresolved
source content remains unresolved rather than being copied from a neighbour.
