# Original-owned 2D material field

Use only after an actual enlarged natural-surface observation locates horizontal row bands, while source projection, source samples, complete/visible masks and surrounding native parts are retained. This is colour interpolation, not semantic generation or missing texture recovery. For material that needs explicit 3D faces/rings/edges, retain those separately.

The source-material-grid CLI takes baseline_hash, source_hash, unit, source_evidence and visible_mask{path,sha256}; it reuses the exact visibility mask bound to a previously sampled SVG surface and changes only that owner's content. This non-completed surface route returns a regular scoped SVG subtree proposal, not a native-leaf writer grant. Original hidden completion uses the existing explicit surface program instead. The existing source_gradients constructor and source-material surfaces also accept field_sampling="bilinear_grid", vertical_subdivisions=4 (bounded2..8), with unchanged RGB, visible, complete and deps. Recurse first: max dimension400, area60000, at least2samples per axis. The program retains source-centre coordinates and bounded SVG fields, stores the original compressed/checksummed grid locally in the SVG master, and routes paper through the existing source_mesh carrier. Paper uses a two-input PDF sampled vector shading with bilinear interpolation; it does not add image XObjects. SVG display uses bounded sub-row gradients and must be assessed on its actual host independently from PDF.

Reopen a previously frozen material through actual hash-bound revisit and explicit own-unit source/style observation. Replace only observed surface owners, with all native housings, radios, labels, formulas and approved geometry protected. Keep original score ROI/masks/floors. Estimate does not accept a drawing: save/render the actual PPT, inspect each changed surface and its complete semantic context, retain only independent gains/no unauthorized changes. Assess PDF separately; interpolation can trade a colour metric against edge/foreground, and a small source grid has limited observable detail. No whole-icon bitmap or global redraw is authorized by this operator.

Reuse source RGB, masks and cached methods; do not serialize them repeatedly into prompts. Default legacy horizontal-row artwork stays unchanged until an explicitly located material repair selects this method.

Saved actual local material drawings locate a second cause: antialiasing many narrow opaque row rectangles mixes each field with the mean underlay and creates horizontal bands. Original2Dinterior field strips use crispEdges; the original owner clip/native silhouette remains antialiased and unchanged. A local SVG/PDF asset outcome is an estimate for native display, not evidence that Office honors it; evaluate the saved PPT before retention.

When actual native SVG material still fails its own source targets, office_display="preview" requires display_evidence{path,sha256}: a saved failed_native_result (PPT, scene, preview and render hash descriptors) and before.pptx bound to current selected baseline. The program re-evaluates that owner and verifies unchanged native frames plus original2Dmaterial lineage. It retains the exact pure vector mother and uses the already drawn HD local-converter field for only this material. This is a measured compatibility trade, not a claim that native SVG rendered correctly or an authorization to replace a whole icon/page. The resulting saved PPT and vector paper outcomes must each be assessed; a local proposal does not satisfy the final owner. Resource cache identity includes both field-code and display evidence so historical metadata is not overwritten.


After an actual native flat-paint attempt fails a natural source material's own accuracy, the existing original RGB-field constructor may use `continuous_contours` plus an exact `contour_basis` (`source_hash`, actual description, hashed `fit_evidence`) instead of tracing a colour-class binary clip. Reuse the original source RGB, owned masks and source-fitted native contour geometry; retain the separate natural body/upper/lower ownership and unchanged actual ancestor frame. This is a pure SVG component accuracy/editability trade, assessed on that independent natural part and its protected neighbours. A clear continuous contour is different from regenerated semantic texture; original blur/material ambiguity remains disclosed and independently reviewed. Without bound fitting evidence it is rejected. The contour and evidence are cache identity inputs. Existing native fields, original masks/targets and previously satisfactory properties do not change merely to admit this route.


For a saved RGB mother that spans several natural parts, `core.source_gradients.excise_original_part` takes its exact original visible/complete masks and a separately source-declared natural exclusion mask. It regenerates the remaining field with the same source RGB/frame/recipe and direct remaining semantic contours, preserving the old mother and avoiding an outer SVG wrapper. This removes a named natural part rather than appending fragments over it. Remaining body pixels still need the actual local preservation comparison: equal source data or native frames alone are insufficient renderer evidence. A measured exact SVG material may retain its pure vector mother with its continuous-contour HD compatibility preview when native display is demonstrably worse; do not reuse a different unmeasured mother or substitute a binary source-sample upscale.

A natural-part excision is restricted to its independently declared original reference mask, mapped into the old material frame. It cannot remove other material under a broad regional mask. The existing repair-scope decision now automatically compares actual saved before/after pixels in every retained original material mask, binds the exact baseline mother/frame and blocks adoption for any changed non-target sample. This protects unchanged body/material even when its whole-icon score happens to improve, without rerunning unrelated page metrics or claiming new satisfaction.
