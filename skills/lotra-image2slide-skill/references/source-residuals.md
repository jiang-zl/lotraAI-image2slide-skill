# Locate actual independent visual-part residuals

When an actual icon/leaf score is low and its cause is not located, call `source-residuals TASK REQUEST --out RESULT` with baseline_hash, source_hash and one masked visual unit. Use the existing native glyph/formula/relation routes for those profiles. Recurse to a natural part first: at most400px per dimension and60000pixels. The program caches the actual original/saved-render canvas, unchanged source masks/protocol/targets and its own code hash. It produces one bounded board plus exact original-coordinate missed/excess edge and foreground fragment locations, and an owned RGB residual field. It changes no source, drawing, target or observation.

Read the board before assigning a root cause. An original reference mask can exclude a foreign oval border while the candidate's colour selector counts that border as extra component ink. A low component-edge score then reports an ownership asymmetry, not a malformed component. Equally, missing original internal parts can be genuine geometry debt. Numeric fragments alone cannot decide which. Locate the named source layer/feature and earliest inconsistent source/program/native/render artifact. Foreign-layer exclusions must have original evidence; original true component gaps and complete foreground remain protected.

Use source-fragments for original source membership ambiguity, ordinary source_correction/source-layer-domain for a confirmed original comparison-domain fault, or a bounded native/SVG material/geometry/host repair for an actual drawing fault. Keep prior masks/definitions/floors/history and compare saved before/after under the same amended source definition. A source-definition correction earns no drawing improvement. Never mask a candidate defect away or narrow a domain merely because it improves a score. The full component/neighbor relations and unauthorized-change protection still apply. The residual board is localized drawing inspection; it does not launch a full-slide functional validation campaign.

Uniform native fill response requires actual original exterior/material samples. The protocol's alpha-compositing background is not necessarily that material's exterior plane. For source shading that a uniform paint cannot reproduce, reuse existing bounded original-colour SVG fields with semantic material masks and explicit completed underlay; preserve native owner/group frames. Keep the pure SVG paper master and independently measure actual Office appearance. Original blurry RGB interpolation is not proof of newly reconstructed HD detail.

An exterior-only source-layer-domain correction now reuses the exact existing foreground descriptor when all foreground bytes/frame are unchanged. This avoids false invalidation of original occlusion dependents; real mask/ROI changes still propagate. Partial own improvement, minimum met and unmeasured remain distinct.
