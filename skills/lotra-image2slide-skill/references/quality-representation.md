# Component quality and representation

The minimum component is a natural semantic object, not a primitive and not an entire figure. Native shapes, embedded pure SVG and permitted HD raster have distinct edit levels. Native text/math/relations remain separate. Parts/nodes are optional enhancements. Source positions and aspect ratio remain authoritative.

`method.svg_asset` points to an immutable task-local SVG and a bound PNG compatibility preview: `{path,sha256,preview:{path,sha256}}`. The program embeds the SVG resource using Office `svgBlip`; preview pixels are not the vector master. Pure SVG rejects raster images, scripts, animations and external dependencies. Preview requires optional project-local CairoSVG or an explicit host adapter. SVG shaders/effects need actual render observation; no silent effect loss.

Source 3D analysis records camera subtype, mount/body/lens connections, projected faces, shading direction and material. Use source-matched assets; adapt orientation/colour carefully. Faces share vertices; depth and vertical height are independent. Cylinders have projected ellipses and smooth curves. Plastic uses broad smooth gradients, metal narrower restrained bands, lens glass a dark cavity with coloured specular reflections. Do not add unseen semantic parts or unnecessary photorealistic shadows.

Each component's immutable `quality_profile` records edit_level, metric_focus and important_properties. `quality_policy.measure` computes conditional foreground IoU, edge chamfer, colour error, texture, contrast and curvature. These are diagnostics: increasing curvature or edge energy is not automatically better. Host judges semantic parts, material and aesthetics from paired actual views. Scalar profile scores and numerical source metrics remain separate.

HD raster requires actual local comparison with a source-bound vector baseline and substantial important quality gain; preserve critical semantics, layout, family consistency and frozen properties. File size alone cannot justify loss of vector nature. A pure SVG near-tie may trade internal editability for compactness. Bitmaps disclose semantic reconstruction and effective resolution at paper/reuse size. Blur is not a target for PSNR/SSIM.

Complex colour artwork should use coherent boundary contours, appropriate curves and gradients. Fine painted or photographic texture can use source-resolution colour runs encoded compactly inside one SVG; do not expand them into millions of native DrawingML rectangles. Compare actual texture before contour simplification: deleting tiny colour regions can flatten cheeks and erase eyelids. Count paths/commands, uncompressed slide XML and actual ZIP/media size. Keep compatibility previews clear at intended slide size without oversampling every tiny photo to a full-page bitmap. Maintain an actual quality baseline; simplify only when its target metrics and observations remain acceptable. Cache assets by content and converter version, not task position.

Scientific measurements, medical displays and phenotype evidence retain observed morphology and values; do not invent sharper structures through generative completion. Decorative artwork and ambiguous photographic illustration can use disclosed semantic reconstruction. This distinction belongs in the source plan before choosing enhancement.

Loop repair records owner/ROI/property, expected/actual, root-cause evidence, minimal write set, important metric deltas and protected scope. Re-evaluate only affected units plus necessary relations. Keep best; missing evidence stays unmeasured. Paper PDF/SVG comes from selected artwork and preserves vector content; mixed output is reported as mixed, not full vector.


Smooth 3D surfaces are a geometric route. `source-material` returns RECURSIVE_NATIVE_SURFACE_PLAN_REQUIRED for a three_dimensional unit rather than silently tracing the whole icon into many colour patches. Read original enlarged housing/lens/support/signal parts; build independent measured presets, complete paths and restrained native gradients using the existing scoped method interface. Preserve LED/vent/rim density and original projection. Fine texture belongs in its own source-bound artwork field. A source-bound SVG proposal remains possible when actual important-part fidelity warrants it. This transition is a drawing plan, not quality acceptance. Natural-part metrics and semantic content must still pass independently; a smooth-looking camera cannot omit its IR LED array.

For source-observed continuously shaded materials, freeze histogram_mode=trilinear with the original RGB grid and unchanged floors before further drawing. Keep hard-bin TV as a diagnostic. If an inherited protocol was inappropriate, archive the original reading and recompute prior/new actual results with one corrected protocol; report measurement correction separately from real drawing gain.
