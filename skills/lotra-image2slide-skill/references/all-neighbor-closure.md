# All-neighbor and complete assembly closure

The host interprets original roles and supported geometry. The program freezes
this inventory independently of candidate success receipts. Each role has a
stable ID, native mappings, conservative painted bounds, finite source geometry,
source evidence, coordinate units, source-only localization uncertainty and
measurement method. Unknown bounds or empty required mattes block acceptance.
Native groups use descendant paint unions. Actual glyph ink envelopes are
reported as envelopes; contact/containment of actual glyph shapes needs a host
owner matte. Unsupported geometry is never replaced with a nominal group box.

`neighbor-check TASK bind --request SOURCE.json --out RESULT.json` freezes the
source inventory. `compile` runs range discovery and compiles predicates;
`report` independently enumerates every unordered pair in bounded blocks,
checks the registry, then measures current saved native geometry. `next` emits
failures and the dependent check set for the host's bounded repair plan.

All coordinates use the frozen original-to-slide transform. With the long image
edge normalized to 1000, coverage radius is `max(4,3*max(stroke_i,stroke_j),
0.20*min(short_side_i,short_side_j))`. This is an engineering coverage radius,
not an accuracy tolerance. Current radius is floored by the source radius.
Required pairs union source, current, confirmed and retained pairs. No top-k,
same-root restriction, lock, reuse or 'unrelated' decision deletes obligations.
The independent audit never reads the spatial index's returned pair list to
decide what to test. It recomputes source and actual predicates by blocked
all-pair enumeration and compares the resulting sets.

Every pair compiles identity, relative center vector, visible gap,
overlap/containment, applicable layer and current-execution predicates. Actual
saved contours have bounded numerical precision; unsupported paint needs an
actual isolated host matte. Numerical source intervals must be frozen before
candidate comparison. A source-specific target retains its measured source
basis. Layout improvement needs an authorized frozen target, not a tolerance
changed to rescue a failure. Non-applicability records the program condition.

Missing pairs/predicates, wrong dependencies, unknown measurements, stale
artifacts and numerical failures block `quality-loop run` and final export.
Every predicate also enters recursive result closure. Repair targets come from
failed measurements; remeasure every relation that depends on a changed role.
Unchanged evidence reuse requires unchanged dependencies, source and checker.

Composite assemblies separately declare required roles and providers. Provider
scope is part, assembly or inherited; every role still needs an actual current
implementation and measurement. A partial constructor never proves a whole
assembly. Required pair IDs link all assembly relations to actual execution.
Original provider scope and source roles are frozen separately from the mutable
`neighbor_execution` receipt. `refresh-execution` may refresh changed current
providers only after exact finite native replay; copying current hashes into
original source facts is not a completion mechanism.

`neighbor-check TASK repair --request PLAN.json --out RESULT.json` accepts
only the exact current baseline/source hashes and at most eight movable roles
with distinct x/y axes and finite budgets (at most 32 source pixels). There are
no caller coordinates, caller XML or replacement tolerances. The program solves
all incident predicates, recomputes affected ancestor paint unions, preserves
every other native property/resource and records the write/check sets. Flat
contact derivatives have a bounded deterministic coordinate/ray fallback; an
infeasible batch writes no candidate. The saved native XML must reproduce the
solver exactly. Prediction is separate from actual execution: render the new
PPT, `capture` missing owner mattes in bounded batches, `refresh-execution`,
`compile`, then `report` and the whole quality loop. Newly close objects join
the current set even if they were outside the repair's predicted closure.

Every state writer owns a task-local lock and the hash of the state it read.
An obsolete reader or foreign writer cannot overwrite a newer execution row.
Uncommitted artifacts remain available for exact content-based recovery; they
do not automatically become executed or accepted.

`core/folded_paper.py` constructs editable body/fold fills, a continuous outer
path and an open crease. A/B/C come from one parameter set. AB belongs to the
outer path; AC/CB belong to the crease. Source-only fitting models raster blur
as a nuisance and exports sharp vectors. Native acceptance independently reads
vertices, closed/open paths, fill union, edge ownership, line widths and z-order.
Source-local fit, actual host render and all neighboring objects remain required.
PPT does not provide live shared-vertex constraints after arbitrary manual
ungrouped edits; reimport detects changed relations without overwriting user intent.

Behavioral regression covers wrong geometry/dependency binding and specified
bad saved artifacts, not just edited final score fields. The finite guarantee is
complete execution over the valid frozen role inventory and its uncertainty;
source semantic completeness still requires host interpretation and recursive
source-residual checks. Never claim an unrecognized feature has been disproved.
