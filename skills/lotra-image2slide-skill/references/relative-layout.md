# Source-bound relative layout

Load this only for source-layout planning or a position/collision defect.

The host confirms original semantics and ownership; the program binds and solves relationships. New task source specs require layout_review{source_hash,evidence,scope,important_relation_ids}. Review the original natural pairs, container content and intended overlaps. If no critical relation applies, give a concrete original-supported scope explanation and an empty list. Every named important relation must have an executable relative_layout measurement. Omitting the review cannot silently complete the source step.

Use the installed Python entrypoint:
    sci_rebuild.py relative-layout TASK discover --out CANDIDATES.json
    sci_rebuild.py relative-layout TASK bind --request ORIGINAL_RELATIONS.json --out REPORT.json
    sci_rebuild.py relative-layout TASK propose --request BOUNDED_REQUEST.json --out PROPOSAL.json
    sci_rebuild.py relative-layout TASK report --out REPORT.json

Discovery suggests nearby original part pairs only. Observe in batches of at most8; do not turn bounding-box adjacency into a claimed source intent. Important relations can also be declared directly in source_spec.relations, with measurement{kind:relative_layout,contract:...} and independent frozen metrics. For a new located relation on an existing result, bind needs baseline_hash and contracts; it adds immutable source records without resetting the task or existing scores.

A contract contains schema:relative-layout-1, id, source_hash, original canvas [w,h], source_view{path,sha256}, source_evidence, original source_bounds{saved_name:[x,y,w,h]}, objects:[a,b], kind and interval:[lower,upper]. These bounds must be owned visible original contours, not convenient scene frames. State explicitly how blur/sampling informed a fixed interval. Keep critical relations independent.

Kinds:
- separation: axis:x|y, actual painted b.min minus a.max must stay within the source gap interval.
- containment: a is content; b is the actual container BODY. body{shape:rect|rounded_rect,radius_ratio:...} excludes tails, shadows and the group frame. Both strokes count. The interval bounds the signed inner-border clearance. Optional target_top_left comes from original owned content; preserve the existing size and style.
- alignment: axis plus anchor_a/anchor_b:min|center|max; freeze the source-relative signed anchor offset.
- intentional_overlap: freeze the source paint-envelope overlap area and paint_order:a_before_b|b_before_a. An intended overlap must not become a blanket no-overlap rule. Area here is explicitly a contour envelope, not pixel IoU.

Measure from the saved native DrawingML, composing parent coordinate transforms, exact quadratic/cubic extrema and painted line widths. Empty native text bodies are not ink. Supported contours keep group metadata out of visual bounds. Unknown guides/arcs/rotated artwork, text glyphs, pictures, arrowheads, dashed strokes and effects enter the automatic actual-owner provider. `render-working` requests missing native owner mattes in batches of at most16 from the same saved PPTX and actual full-page renderer. The program reads black/white alpha support on the complete original canvas at least4×, including parent transforms and font/host context. Its 50% alpha contour is a sampled paint envelope, not a filled text frame or pixel collision certificate. An empty, stale, wrong-owner or wrong-host capture stays required_unmeasured. Original source extents and intervals remain independently frozen; the candidate never supplies original expected bounds. Occlusion, opaque cores and genuine openings remain separate mandatory composition checks. Existing ink-spacing masks remain an independent route, with original/saved-owner/hash bindings. Never call envelope overlap pixel overlap.

propose needs baseline_hash, one saved leaf object, allowed axes and max_translation_px. It uses the same actual ink evidence as the final gate, intersects all applicable source constraints, freezes peers and returns a bounded deterministic translation. Containment aims inside its frozen clearance interval; finite endpoint/midpoint trials cannot widen that interval. A conflict returns INFEASIBLE_WITH_CURRENT_WRITE_SCOPE; it never expands write permission or shrinks another icon. Rounded-domain/complex constraints that cannot be solved by translation return an explicit next action. Submit the proposal through native-proposal-action or `source-layout-repair TASK REQUEST --out RESULT`.

The finite source-layout repair request contains `expected_baseline_sha256` and1–8 distinct `items: [{object, axes: ["x", "y"], max_translation_px: NUMBER}]`. The host selects semantic owners and a bounded write scope; it cannot provide coordinates, translations or executable payloads. The program jointly solves all affected frozen relations using bounded deterministic SLSQP (two fixed starts at most,128 iterations each), keeping up to0.25 original pixel inside each finite interval for native sampling. Starts are zero and an independently frozen original-owned anchor; there are no random restarts or candidate registration. The second start handles a flat derivative where signed containment is limited by a different side. It preserves parent transforms with their inverse affine mapping and changes only named leaf positions. A conflicting/infeasible result is rejected before candidate writing.

An item may instead declare `operation: "source_body_frame"` with an object and finite `max_translation_px` budget. This restores a supported simple native rectangle's frame from its independently frozen containment `source_bounds`, accounting for the preserved stroke. Both position and extent changes must fit the budget. Conflicting original bounds, complex/tail/effect/rotated bodies and caller coordinates are rejected. This operation can share one batch with the contained text and its header: the original body frame is constructed first, then the program jointly solves their translations. Header/body separation and header/container clearance are separate source relationships; a successful body-containment check alone never certifies text layout. Original glyph ownership includes raised/lowered mathematical spans, all rows and all relevant siblings.

A committed action records original contract hashes, original-derived body frames, prior/candidate identities and decisions. The two-attempt budget follows each semantic owner, operation and frozen source geometry; changing caller order, free prose, interval IDs or the numeric action budget cannot reset it. A zero-effect native action is refused. An interrupted uncommitted output can be recovered only when every ZIP payload equals the deterministic constructor; different files remain untouched. Actual rendering and the complete loop remain mandatory. Exact constructor comparison protects every translated owner's text, font, style, shape and ZIP resources; a declared body operation permits only its original-derived frame fields, and all other owners remain individually protected. Fixed-ROI SSIM and clarity changes remain observations, without registration or a fabricated replacement score. Acceptance requires the exact protected constructor and every actual layout relation passing.

Native construction and authorized user edits run the saved-contour gate before the result becomes active. A known violated affected relation blocks the candidate. Unsupported geometry can proceed to actual rendering as unresolved, but cannot be retained until measured. Retention also requires the actual saved-render binding and each affected relation's own interval. Whole-page SSIM/PSNR cannot compensate it. Keep relation reports next to immutable versions; code/contract/pptx hashes invalidate the local cache precisely.

Use the ordinary loop: source pair -> bound relation -> minimal proposal -> saved native gate -> actual affected pair view -> independent effect -> retain or roll back. Preserve all unrelated native fields, assets, source text/math and approved artwork. Stop a branch after two consecutive attempts at the same cause without substantive visible gain. New source corrections get new identities/evidence; never rewrite an old interval to accept a failed result.


Actual ink fallback reuses the existing ink-spacing program. A host observing unsupported native/text/image ink may write the candidate version folder's relative-layout-masks.json with schema:relative-layout-ink-provider-1, source_hash, candidate_hash and bindings[{id,ownership_evidence,ink_spacing:{path,sha256}}]. Each ink-spacing-1 contract binds this saved PPTX/render receipt and one pair with the same relation ID, saved object paths, fixed ROIs and original/candidate full-canvas masks. The source preview must be the exact full original sampled with LANCZOS to the actual render canvas, preserving aspect ratio; no per-component registration or enhanced reference is permitted. Source mask extents must agree with frozen owned source_bounds within sampling uncertainty. The existing spacing provenance gate must succeed, then the typed source relationship is independently measured at original pixel units. This provider resolves paint envelopes from real ink; it cannot waive native body topology, scientific content, protected fields or an unsupported freeform interior. Missing/stale/ambiguous ink evidence remains actionable and blocks retention.

Native local position edits mirror only their authorized saved position fields into the scene and bound leaves; stale recipes stay snapshot_only. A native_host_tool route skips the alternative-renderer prepass and waits for the actual declared host. Two failed local-edit attempts stop that branch, preserving its approved best.
