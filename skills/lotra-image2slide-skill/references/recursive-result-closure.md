# Complete recursive execution and result closure

The original region tree and actual native layer tree are independent. The
runtime builds the union of all source regions, their critical features, source
quality parts/properties, source geometry contracts, connections and saved
native descendants. `quality-loop run` and export require this same closure.

Source discovery READY is not output acceptance. Every obligation has explicit
dependencies and required checker IDs. Programs check set equality, current
source/PPT/render/implementation identity, concrete measured results and
bottom-up dependency closure. Missing/failed/unmeasured checks block parents.
Groups have no own pixels; their children still require independent checks.
New leaves do not inherit a root's approval. Every rebuild triggers a new full
inventory; retained local observations can be reused only with identical bound
source, policy, native dependency and observed pixels.

Use `recursive-check TASK report --out REPORT.json`. Review the located
`unclosed` IDs and their actual check receipts. Do not report check counts as
quality. Semantic correctness still depends on faithful original interpretation;
executable coverage proves traversal of the discovered set, not omniscience.

Freeze exact original features before reconstruction with `source-feature TASK
bind --request REQUEST.json --out RECEIPT.json`. Each unit uses the finite
`source-feature-function-1` schema: source_hash, source_evidence, bbox, parts and
features. Parts are polygon/polyline/ellipse/rect/analytic arc with original
coordinates, roles, paint and located source evidence. Features bind explicit
parts. Every part must belong to a feature. Unknown icon families use observed
geometry; a category name cannot replace silhouette, subtype, projection or
internal features. Clarity/material enhancements are separately authorized;
they cannot erase original structural features.

`recursive-check TASK plan --request PLAN.json --out RECEIPT.json` compiles a
plan against the exact current complete report. Supply source_hash,
check_report and actions[{id,targets,operator,reason,expected_change,
protected_scope,request}]. Targets are registered obligation IDs. Operators
are source_structure, source_text, source_layout and connector_geometry, with
their existing finite request schemas. `recursive-check TASK execute --request
{plan: RECEIPT.plan, action: ID} --out RESULT.json` dispatches program actions.
After geometry changes rerender, analyze current checks and plan the next step.
Every registered action must execute and its target must close on the actual
current result. Replan if the baseline changes. A no-gain or failed branch stays
in history; it cannot be relabeled successful or remove obligations.

Source and native geometry/paint are checked independently with existing
frame/content/topology/appearance and complete constructor replay operators.
Blurred originals retain reported SSIM/PSNR diagnostics and purpose-specific
policies. Neither old baselines nor weighted appearance compensate missing
features, incorrect scientific/text content, relation failures or unchecked
children.
