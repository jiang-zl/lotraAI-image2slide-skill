# Source-fitted signal icons and associated text

Use for `signal_source`, a `signal_function` method, or `signal-semantics`. A signal-shaped icon has an executable function, its source-supported parameters or sampled source points, and independent original/current measurements. Never synthesize scientific measurements. A schematic source wave can use `observed_spline`, `carrier_envelope`, or `damped_pulse`; preserve original envelope, peaks, corners and phase structure. PCHIP observed functions become editable native cubic segments.

The host determines whether nearby original text labels a signal. Bind actual text owner, exact literal and located source evidence. Strong/weak auxiliary predicates normally concern peak-to-peak amplitude or RMS energy. Frequency ordering requires explicit text or observed source order; strength alone does not imply higher frequency. A contradiction returns to original observation; do not rewrite the source to match a generic semantic expectation.

Measure original and actual saved-render signals at one common original-pixel scale. Never normalize each signal's amplitude independently. Report SSIM, PSNR, curve RMSE, maximum vertical distance, symmetric Chamfer and Hausdorff distances, peak-to-peak amplitude, RMS, envelope bins, peak count and dominant cycles per icon. Without an actual time axis, cycles per icon are not Hz. Constant or identical pixels use explicit measured identity status, not fabricated or nonfinite metrics.

Each declared source signal remains a final-gate obligation even when its candidate curve is missing. Missing source extraction, label binding or metric evidence returns a located work packet. Pixel/curve thresholds bind source-specific evidence; parent approval and a weighted appearance score cannot waive a failed required signal relationship.

The host explicitly classifies illustrated waveforms versus `radiating_bands`. Radio bands remain mandatory native closed-band and original part checks; amplitude/frequency metrics do not apply to that source kind. Dense illustrated waveform silhouettes can use `observed_contours`: bounded source-only grayscale level-set functions become editable closed native paths. This retains multiple peaks at the same source x pixel, which a single column-centre spline cannot represent. This constructor embeds no raster and generates no blur; it is unavailable for scientific measurement curves. The finite palette and source evidence are frozen before construction.
